# JS 첫걸음 07 - 함수

> **이전**: [[JS 첫걸음 06 - 반복문|06 반복문]] · **다음**: [[JS 첫걸음 08 - 배열|08 배열]] · **목록**: [[JS 첫걸음 00 - 로드맵|로드맵]]

## 이 레슨에서 배우는 것

1. **함수**가 무엇이고 왜 필요한지
2. 함수를 **만들고**(정의) **부르는**(호출) 법
3. 함수에 값을 건네는 **매개변수**와 **인수**, 그리고 기본값
4. 함수가 결과를 돌려주는 **`return`**

6. 함수를 다른 함수에 건네는 **콜백**

## 1. 함수란?

### 비유로 이해하기: 자판기

음료 자판기를 생각해 봅시다.

- 돈과 버튼 번호를 **넣으면** (입력)
- 자판기 안에서 정해진 일이 **일어나고** (처리)
- 음료가 **나옵니다** (출력)

자판기 안이 어떻게 생겼는지 몰라도, 넣는 법과 나오는 것만 알면 몇 번이든 쓸 수 있습니다.

**함수**(function)는 코드로 만든 자판기입니다. 여러 줄의 코드를 **하나로 묶고 이름을 붙여 두면**, 필요할 때마다 이름만 불러서 그 코드 묶음 전체를 실행할 수 있습니다 (입문서 p.143: "Calling a function means an entire group of statements will get executed."). MDN은 함수를 "a set of statements that performs a task or calculates a value"라고 설명하고, 입력을 받아 출력을 돌려주는 것이 함수의 모습이라고 덧붙입니다.

### 사실 이미 써 봤어요

`console.log()`, `Number()`, `Math.floor()`처럼 **이름 뒤에 괄호 `( )`가 붙은 것**은 모두 함수입니다 (입문서 p.143: "We can recognize functions by the parentheses at the end."). 지금까지는 JavaScript가 미리 만들어 둔 함수를 썼고, 이번 레슨에서는 **내 함수를 직접** 만듭니다.

### 왜 함수를 만들까요?

- **같은 코드를 여러 번 쓰지 않아도 됩니다.** 한 번 만들어 두고 이름만 부르면 됩니다 (입문서 p.142).
- **고칠 곳이 한 곳뿐입니다.** 같은 코드를 10군데에 복사해 두었다면 고칠 때 10군데를 다 고쳐야 하지만, 함수로 묶어 두면 함수 하나만 고치면 됩니다 (판단).
- **코드에 이름이 붙어 읽기 쉬워집니다.** `calculateTotalPrice()`라는 이름만 봐도 무슨 일을 하는지 알 수 있습니다 (판단).

## 2. 함수 만들기와 부르기

### 2.1 만들기 (정의)

```js
function sayHello() {
  console.log("안녕하세요!");
  console.log("오늘도 즐겁게 코딩해요.");
}
```

| 부분 | 뜻 |
|---|---|
| `function` | "함수를 만들겠다"는 표시 |
| `sayHello` | 함수 이름 |
| `()` | 값을 건네받는 자리 (3절). 지금은 비어 있음 |
| `{ ... }` | 함수가 불렸을 때 실행할 코드 |

(입문서 p.143)

이렇게 함수를 만드는 것을 **정의**(define)한다고 합니다.

> [!warning] 만들기만 하면 아무 일도 일어나지 않아요
> 위 코드를 콘솔에 입력해도 아무것도 출력되지 않습니다. 자판기를 설치만 하고 버튼을 누르지 않은 것과 같습니다. MDN: "Defining a function does not execute it." 입문서도 "JavaScript will not run the statements when the functions do not get invoked."라고 설명합니다 (p.144).

### 2.2 부르기 (호출)

함수 이름 뒤에 **괄호 `()`** 를 붙이면 함수가 실행됩니다. 이것을 **호출**(call, invoke)이라고 합니다 (입문서 p.143).

```js
sayHello();
sayHello();
```

결과:

```
안녕하세요!
오늘도 즐겁게 코딩해요.
안녕하세요!
오늘도 즐겁게 코딩해요.
```

두 번 불렀으니 두 번 실행됩니다. 함수 안의 두 줄을 다시 쓰지 않았는데도요.

### 2.3 함수 이름 짓기

입문서가 권하는 세 가지 (p.144–145):

1. **카멜 케이스**로 씁니다 ([[JS 첫걸음 02 - 변수|레슨 02]]의 변수 이름과 같음). 예: `addNumbers`
2. **무엇을 하는지 드러나게** 짓습니다. `myFunc`보다 `addNumbers`.
3. **동사로 시작**합니다. 함수는 "행동"이기 때문입니다. `hiThere`보다 `sayHi`.

| 좋은 이름 | 아쉬운 이름 |
|---|---|
| `sayHello`, `calculateTotal`, `isEven`, `getUserName` | `hello`, `total`, `doStuff`, `func1` |

## 3. 매개변수와 인수: 함수에 값 건네기

### 3.1 기본 모양

`sayHello()`는 언제나 같은 말만 합니다. **누구에게 인사할지** 함수 밖에서 정해 줄 수 있으면 더 쓸모 있겠죠.

```js
function greet(name) {
  console.log(`${name}야, 안녕!`);
}

greet("철수");
greet("영희");
```

결과:

```
철수야, 안녕!
영희야, 안녕!
```

- 함수를 만들 때 괄호 안에 쓴 `name`을 **매개변수**(parameter)라고 합니다. 함수 안에서만 쓰는 **빈 상자**입니다.
- 함수를 부를 때 괄호 안에 넣은 `"철수"`를 **인수**(argument)라고 합니다. 빈 상자에 **넣어 주는 실제 값**입니다.

MDN *Parameter*:
> - Function parameters are the names listed in the function's definition.
> - Function arguments are the real values passed to the function.
> - Parameters are initialized to the values of the arguments supplied.

### 비유로 이해하기: 자판기 버튼

자판기에 "버튼 번호"라는 **입력 칸**이 있는 것이 매개변수이고, 실제로 누른 **3번 버튼**이 인수입니다 (판단).

### 3.2 여러 개 건네기

매개변수가 여럿이면 **쉼표**로 나눕니다. 인수는 **순서대로** 매개변수에 들어갑니다.

```js
function introduce(name, age) {
  console.log(`나는 ${name}, ${age}살이야.`);
}

introduce("민수", 12);   // 나는 민수, 12살이야.
introduce(12, "민수");   // 나는 12, 민수살이야.  ← 순서가 바뀌면 엉뚱해져요
```

### 3.3 인수를 빠뜨리거나 더 주면?

JavaScript는 인수 개수가 맞지 않아도 **에러를 내지 않습니다** (입문서 p.147–148).

```js
function addTwoNumbers(x, y) {
  console.log(x + y);
}

addTwoNumbers();            // NaN  ← x, y 모두 undefined
addTwoNumbers(1, 2, 3, 4);  // 3    ← 남는 3, 4는 무시
```

- 인수를 안 주면 매개변수에는 **`undefined`** 가 들어갑니다. MDN: "In JavaScript, function parameters default to `undefined`." `undefined + undefined`는 `NaN`입니다.
- 인수를 더 주면 앞에서부터 매개변수 개수만큼만 쓰고 나머지는 무시합니다 (입문서 p.148).

### 3.4 기본값 정하기

인수를 안 줬을 때 쓸 **기본값**을 `=`로 정할 수 있습니다 (입문서 p.147–148). MDN: "Default function parameters allow named parameters to be initialized with default values if no value or `undefined` is passed."

```js
function greet(name = "친구") {
  console.log(`${name}야, 안녕!`);
}

greet();          // 친구야, 안녕!
greet("지수");    // 지수야, 안녕!
```

입문서의 예도 따라가 봅니다 (p.147–148).

```js
function add(x = 2, y = 3) {
  console.log(x + y);
}

add();        // 5   (x = 2, y = 3)
add(6, 6);    // 12  (x = 6, y = 6)
add(10);      // 13  (x = 10, y는 기본값 3)
```

인수를 하나만 주면 **첫 번째** 매개변수에 들어갑니다 (입문서 p.148).

## 4. `return`: 결과 돌려받기

### 4.1 `console.log`와 `return`은 다릅니다

이 레슨에서 가장 중요한 부분입니다. 아래 두 함수를 비교해 봅니다.

```js
function addLog(x, y) {
  console.log(x + y);      // 화면에 보여 주기만 함
}

function addReturn(x, y) {
  return x + y;            // 결과를 돌려줌
}
```

```js
let r1 = addLog(4, 5);
console.log(r1);

let r2 = addReturn(4, 5);
console.log(r2);
```

결과:

```
9
undefined
9
```

- `addLog(4, 5)`는 함수 안에서 `9`를 **화면에 출력**했습니다. 하지만 아무것도 **돌려주지 않았기** 때문에 `r1`에는 `undefined`가 들어갔습니다 (입문서 p.153의 예와 같은 결과).
- `addReturn(4, 5)`는 화면에는 아무것도 출력하지 않고, `9`를 **돌려주었습니다**. 그 값이 `r2`에 들어갔습니다.

### 비유로 이해하기: 계산을 부탁하기

친구에게 "4 더하기 5 좀 계산해 줘"라고 부탁했을 때,

- `console.log`는 친구가 **혼잣말로 "9!"라고 말하고 끝**내는 것입니다. 나는 그 답을 받아 적을 수 없습니다.
- `return`은 친구가 **"9"라고 적은 쪽지를 내 손에 건네주는** 것입니다. 나는 그 쪽지를 상자(변수)에 넣어 두거나, 다른 계산에 쓸 수 있습니다 (판단).

### 4.2 돌려받은 값은 어디에든 쓸 수 있어요

`return`으로 돌려받은 값은 **보통의 값처럼** 쓸 수 있습니다 (입문서 p.153: "we can store the result and continue working with the result of this function in the rest of our code").

```js
function add(x, y) {
  return x + y;
}

console.log(add(1, 2) * 10);             // 30
console.log(add(add(1, 2), add(3, 4)));  // 10  (3 + 7)
```

반복문과 함께 써 봅니다.

```js
function double(n) {
  return n * 2;
}

for (let i = 1; i <= 5; i++) {
  console.log(double(i));   // 2, 4, 6, 8, 10
}
```

### 4.3 `return`을 만나면 함수는 바로 끝납니다

MDN: "The `return` statement ends function execution and specifies a value to be returned to the function caller." 입문서도 "return ends the function"이라고 설명합니다 (p.153).

```js
function checkAge(age) {
  if (age < 0) {
    return "나이는 0보다 작을 수 없어요";
  }
  return `${age}살이군요`;
  console.log("여기는 실행되지 않아요");
}

console.log(checkAge(-1));   // 나이는 0보다 작을 수 없어요
console.log(checkAge(10));   // 10살이군요
```

- `age`가 `-1`이면 첫 번째 `return`에서 끝나므로 두 번째 `return`까지 가지 않습니다.
- 마지막 `console.log`는 어떤 경우에도 실행되지 않습니다. 그 앞에서 항상 `return`하기 때문입니다.

이 성질을 이용하면 [[JS 첫걸음 05 - 조건문|레슨 05]]의 `else if`를 쓰지 않고도 갈림길을 만들 수 있습니다.

```js
function getGrade(score) {
  if (score >= 90) return "A";
  if (score >= 80) return "B";
  return "C";
}

console.log(getGrade(95), getGrade(85), getGrade(50));   // A B C
```

### 4.4 `return`이 없으면 `undefined`

`return`을 쓰지 않았거나 `return` 뒤에 값이 없으면 함수는 **`undefined`** 를 돌려줍니다. MDN: "If omitted, `undefined` is returned." 4.1절의 `r1`이 `undefined`였던 이유입니다.

### 4.5 참/거짓을 돌려주는 함수

`return` 뒤에 비교식을 쓰면 `true`나 `false`를 돌려주는 함수가 됩니다. 이런 함수는 이름을 `is…`, `has…`로 짓는 경우가 많습니다 (판단, [[JS 첫걸음 03 - 자료형|레슨 03]]의 불리언 이름 짓기와 같은 방식).

```js
function isEven(n) {
  return n % 2 === 0;
}

console.log(isEven(4));   // true
console.log(isEven(7));   // false
```

## 5. 함수를 만드는 다른 방법

### 5.1 함수 표현식: 함수를 변수에 넣기

함수도 값처럼 **변수에 넣을 수 있습니다** (입문서 p.144: "variables can contain functions").

```js
const square = function (n) {
  return n * n;
};

console.log(square(4));      // 16
console.log(typeof square);  // function
```

`function` 뒤에 이름이 없고, 대신 변수 `square`에 담았습니다. 이렇게 만든 것을 **함수 표현식**(function expression)이라고 하고, 이름 없는 함수를 **익명 함수**(anonymous function)라고 부릅니다 (입문서 p.167–168). 부를 때는 변수 이름에 `()`를 붙입니다.

`typeof`의 결과가 `function`인 것도 볼 수 있습니다. [[JS 첫걸음 03 - 자료형|레슨 03]]의 표에 없던 결과입니다. 함수도 하나의 값이라는 뜻입니다.

### 5.2 화살표 함수: 짧게 쓰기

함수 표현식을 더 짧게 쓰는 방법입니다. `function` 대신 **화살표 `=>`** 를 씁니다 (입문서 p.149). MDN: "An arrow function expression is a compact alternative to a traditional function expression".

```js
// 함수 표현식
const square1 = function (n) {
  return n * n;
};

// 같은 일을 하는 화살표 함수
const square2 = (n) => n * n;

console.log(square2(5));   // 25
```

화살표 함수의 여러 모양 (입문서 p.149–150):

| 모양 | 예 | 설명 |
|---|---|---|
| 매개변수 여러 개 | `(x, y) => x + y` | 괄호 필요 |
| 매개변수 하나 | `n => n / 2` 또는 `(n) => n / 2` | 괄호 생략 가능 |
| 매개변수 없음 | `() => console.log("hi")` | 빈 괄호 필요 |
| 여러 줄 | `(x, y) => { ...; return x + y; }` | 중괄호와 `return` 필요 |

### 5.3 화살표 함수의 `return` 규칙

여기서 실수가 많이 나옵니다. MDN의 설명:

> In an expression body, only a single expression is specified, which becomes the implicit return value. The block body is analogous to traditional function bodies, where return values must be explicitly specified with the `return` keyword.

- **중괄호 없이** 한 줄로 쓰면, 그 식의 값이 **자동으로** 돌려집니다. `return`을 쓰지 않습니다.
- **중괄호 `{ }`를 쓰면** 보통 함수처럼 **`return`을 직접** 써야 합니다 (입문서 p.154–155).

```js
const add1 = (x, y) => x + y;          // 자동으로 돌려줌
const add2 = (x, y) => { return x + y; };  // 직접 돌려줌
const add3 = (x, y) => { x + y; };     // ⚠️ return이 없음!

console.log(add1(2, 3));   // 5
console.log(add2(2, 3));   // 5
console.log(add3(2, 3));   // undefined
```

> [!warning] 객체를 돌려줄 때는 괄호로 감싸세요
> 레슨 09에서 배울 객체(`{ name: "철수" }`)를 화살표 함수로 바로 돌려주려고 `(name) => { name: name }`처럼 쓰면 `undefined`가 나옵니다. 엔진이 `{`를 객체가 아니라 **함수 몸통의 시작**으로 읽기 때문입니다. MDN: "Returning object literals using the expression body syntax `(params) => { object: literal }` does not work as expected." 해결법은 **괄호로 감싸기**: `(name) => ({ name: name })`.

### 5.4 무엇을 쓸까?

| 방법 | 모양 | 이 시리즈에서 쓰는 곳 |
|---|---|---|
| 함수 선언 | `function add(x, y) { ... }` | 이름 붙은 독립된 함수 |
| 화살표 함수 | `const add = (x, y) => x + y;` | 짧은 함수, 다른 함수에 건네는 함수 (6절) |
| 함수 표현식 | `const add = function (x, y) { ... };` | 다른 사람 코드에서 읽을 수 있으면 충분 |

(판단: 입문서 p.149 "They are most often used for functions that consist of only one statement."를 바탕으로 정리)

> [!note] 화살표 함수와 보통 함수의 차이는 더 있어요
> MDN은 화살표 함수에 "some semantic differences and deliberate limitations"가 있다고 합니다. 이 차이는 객체와 `this`를 배운 뒤에야 의미가 있으므로 이 시리즈에서는 다루지 않습니다. 시리즈를 마친 뒤 [[JavaScript Core Syntax and Modern ES6+ Fundamentals]] 3절에서 볼 수 있습니다.

## 6. 콜백: 함수를 다른 함수에 건네기

### 6.1 함수도 인수가 될 수 있어요

함수는 값이므로 **다른 함수의 인수로 건넬 수 있습니다** (입문서 p.168–169). 이렇게 건네진 함수를 **콜백 함수**(callback function)라고 합니다. MDN: "A callback function is a function passed into another function as an argument, which is then invoked inside the outer function to complete some kind of routine or action."

```js
function doTwice(action) {
  action();
  action();
}

function cheer() {
  console.log("화이팅!");
}

doTwice(cheer);
```

결과:

```
화이팅!
화이팅!
```

`doTwice`는 "받은 함수를 두 번 실행한다"는 일만 합니다. **무엇을** 실행할지는 부르는 쪽이 정합니다.

### 비유로 이해하기: 심부름 쪽지

엄마가 "이 쪽지에 적힌 일을 두 번 해"라고 쪽지를 건넵니다. 쪽지에 "설거지"라고 적혀 있으면 설거지를 두 번, "화분에 물 주기"라고 적혀 있으면 물을 두 번 줍니다. 쪽지가 콜백 함수입니다 (판단).

화살표 함수를 그 자리에서 바로 만들어 건넬 수도 있습니다. 화살표 함수가 가장 많이 쓰이는 곳입니다 (입문서 p.149: "Arrow functions are useful whenever you want to write an implementation on the spot, such as inside another function as an argument.").

```js
doTwice(() => console.log("야호!"));   // 야호! 야호!
```

### 6.2 예: 계산 방법을 건네기

```js
function calc(a, b, operation) {
  return operation(a, b);
}

console.log(calc(3, 4, (x, y) => x + y));   // 7
console.log(calc(3, 4, (x, y) => x * y));   // 12
```

같은 `calc` 함수인데, 건넨 콜백에 따라 더하기도 하고 곱하기도 합니다.

### 6.3 예: 시간이 지난 뒤에 실행하기

JavaScript에 미리 있는 `setTimeout`은 콜백을 받아서 **정해진 시간 뒤에** 실행합니다 (입문서 p.169). 시간은 밀리초(1000분의 1초) 단위입니다.

```js
console.log("시작");
setTimeout(() => console.log("1초 뒤에 나와요"), 1000);
console.log("끝");
```

결과:

```
시작
끝
1초 뒤에 나와요
```

`끝`이 `1초 뒤에 나와요`보다 **먼저** 나온 것에 주목하세요. JavaScript는 1초를 멈춰서 기다리지 않고 다음 줄로 넘어갑니다. 이 동작은 레슨 11(비동기 기초)에서 자세히 배웁니다.

> [!warning] 콜백을 건넬 때는 괄호를 붙이지 마세요
> `doTwice(cheer)`는 함수 **자체**를 건넵니다. `doTwice(cheer())`라고 쓰면 `cheer`를 **그 자리에서 먼저 실행**하고, 그 결과(`undefined`)를 건넵니다. 그러면 `doTwice` 안에서 `undefined()`를 실행하려다 에러가 납니다 (10절 표 참고).

## 7. 맛보기: 자기 자신을 부르는 함수 (재귀)

함수 안에서 **자기 자신을 다시 부를** 수도 있습니다. 이것을 **재귀**(recursion)라고 합니다 (입문서 p.163).

```js
function countDown(n) {
  console.log(n);
  if (n > 0) {
    countDown(n - 1);
  }
}

countDown(3);   // 3 2 1 0
```

**멈추는 조건**(`n > 0`)이 꼭 있어야 합니다. 없으면 자기 자신을 끝없이 부르다가 `RangeError: Maximum call stack size exceeded` 에러로 멈춥니다. 반복문으로도 할 수 있는 일이 많아서, 입문 단계에서는 "이런 방법도 있다"는 정도만 알면 됩니다.

## 8. 정리

| 낱말 | 뜻 |
|---|---|
| 함수 | 이름을 붙여 묶어 둔 코드. 필요할 때 불러서 실행 |
| 정의 | 함수를 만드는 것. 만들기만 하면 실행되지 않음 |
| 호출 | `이름()`으로 함수를 실행하는 것 |
| 매개변수 | 함수를 만들 때 괄호 안에 쓴 이름 (빈 상자) |
| 인수 | 함수를 부를 때 괄호 안에 넣은 실제 값 |
| 기본값 | `(name = "친구")`. 인수가 없거나 `undefined`일 때 쓰는 값 |
| `return` | 결과를 돌려주고 함수를 즉시 끝냄. 없으면 `undefined` |
| 함수 표현식 | `const f = function () { ... };` 함수를 변수에 담기 |
| 화살표 함수 | `const f = (x) => x * 2;` 짧은 함수. 중괄호 없으면 자동 `return` |
| 콜백 함수 | 다른 함수에 인수로 건네는 함수 |

## 9. 자주 하는 실수

### 9.1 `console.log`로 출력만 하고 `return`을 빠뜨림

```js
function add(x, y) {
  console.log(x + y);
}
const total = add(2, 3) * 10;   // 화면에 5가 출력되지만, total은 NaN  (undefined * 10)
```

결과를 다른 곳에서 쓰려면 `return x + y;`로 돌려줘야 합니다.

### 9.2 `return` 다음에 줄을 바꿈

```js
function add(a, b) {
  return
    a + b;
}
console.log(add(1, 2));   // undefined
```

`return` 바로 뒤에서 줄을 바꾸면, 엔진이 `return` 뒤에 세미콜론을 자동으로 넣어 버려서 **아무것도 돌려주지 않는 `return`** 이 됩니다. MDN *return*: "This makes the function return `undefined` and the `a + b` expression is never evaluated." 돌려줄 값은 `return`과 **같은 줄**에서 시작합니다.

### 9.3 그 밖의 실수

| 잘못 쓴 코드 | 결과 | 무엇이 문제인가 |
|---|---|---|
| 함수를 만들기만 하고 부르지 않음 | 아무 일도 안 일어남 | `sayHello();`처럼 괄호를 붙여 불러야 합니다. |
| `sayHello;` (괄호 없음) | 실행되지 않음 | 괄호가 없으면 함수를 부르는 것이 아니라 함수 자체를 가리킵니다. `console.log(sayHello)`는 Node.js에서 `[Function: sayHello]`를 출력합니다 (브라우저 콘솔은 함수 내용을 보여 주는 등 모양이 다를 수 있음). |
| `const add3 = (x, y) => { x + y; };` | `undefined` | 화살표 함수에 중괄호를 쓰면 `return`이 필요합니다. |
| `doTwice(cheer());` | `TypeError: action is not a function` | 콜백을 건넬 때 괄호를 붙이면 함수 대신 실행 결과(`undefined`)를 건넵니다. `doTwice(cheer)`. |
| `const` 함수 표현식보다 위에서 호출 | `ReferenceError: Cannot access 'square' before initialization` | 아래 상자 참고. |

> [!note] 함수를 만들기 전에 부를 수 있을까?
> `function`으로 **선언한** 함수는 선언보다 위에서 불러도 동작합니다. `const`에 담은 함수 표현식이나 화살표 함수는 담기 전에 부르면 에러가 납니다. MDN: "Function hoisting only works with function declarations — not with function expressions." (*Functions* 가이드)
> ```js
> console.log(square(5));   // 25  ← 아래에 있어도 됨
> function square(n) { return n * n; }
>
> console.log(cube(2));     // ReferenceError: Cannot access 'cube' before initialization
> const cube = (n) => n * n * n;
> ```
> 헷갈리지 않으려면 **함수는 쓰기 전에 위에서 먼저 만든다**고 기억하면 됩니다 (판단). [[JS 첫걸음 02 - 변수|레슨 02]]의 "변수는 만든 다음에 쓴다"와 같은 원칙입니다.

## 10. 확인 퀴즈

**Q1.** 아래 코드는 무엇을 출력할까요?
```js
function triple(n) {
  return n * 3;
}
console.log(triple(4) + triple(1));
```

> [!question]- 정답 보기
> `15`입니다. `triple(4)`는 12, `triple(1)`은 3을 돌려주고, 12 + 3 = 15입니다.

**Q2.** 아래 두 줄은 각각 무엇을 출력할까요?
```js
function welcome(name = "손님") {
  return `${name}님 환영합니다`;
}
console.log(welcome());
console.log(welcome("지민"));
```

> [!question]- 정답 보기
> `손님님 환영합니다`, `지민님 환영합니다`입니다. 인수가 없으면 기본값 `"손님"`을 씁니다.

**Q3.** 아래 코드에서 `result`에는 무엇이 들어 있을까요? 그 이유는?
```js
function say(word) {
  console.log(word);
}
const result = say("안녕");
```

> [!question]- 정답 보기
> `undefined`입니다. `say`는 `"안녕"`을 화면에 출력하기만 하고 `return`하지 않으므로 아무것도 돌려주지 않습니다. (콘솔에는 `안녕`이 출력됩니다.)

**Q4.** 두 수 중 큰 수를 돌려주는 함수 `maxOf(a, b)`를 만드세요. `maxOf(3, 8)`은 `8`, `maxOf(10, 2)`는 `10`이어야 합니다.

> [!question]- 정답 보기
> ```js
> function maxOf(a, b) {
>   if (a > b) {
>     return a;
>   }
>   return b;
> }
> ```
> 삼항 연산자로 `const maxOf = (a, b) => a > b ? a : b;`처럼 쓸 수도 있습니다.

**Q5.** 아래 함수를 화살표 함수 한 줄로 바꾸세요.
```js
function isAdult(age) {
  return age >= 19;
}
```

> [!question]- 정답 보기
> ```js
> const isAdult = (age) => age >= 19;
> ```
> `isAdult(20)`은 `true`, `isAdult(15)`는 `false`입니다.

**Q6.** 입문서 퀴즈 4번입니다 (p.171). 무엇이 출력될까요?
```js
let test2 = (num) => num + 5;
console.log(test2(14));
```

> [!question]- 정답 보기
> `19`입니다. 중괄호가 없으므로 `num + 5`가 자동으로 돌려집니다.

**Q7.** 아래 코드에서 `doTwice(cheer())`가 에러를 내는 이유는 무엇일까요?
```js
function doTwice(action) {
  action();
  action();
}
function cheer() {
  console.log("화이팅!");
}
doTwice(cheer());
```

> [!question]- 정답 보기
> `cheer()`처럼 괄호를 붙이면 `cheer`가 **먼저 실행**되어 `화이팅!`을 한 번 출력하고, 그 결과인 `undefined`가 `doTwice`에 건네집니다. `doTwice` 안에서 `undefined()`를 실행하려 하므로 `TypeError: action is not a function`이 납니다. `doTwice(cheer)`로 고칩니다.

**Q8. (직접 해 보기)** 가로와 세로를 받아 직사각형의 넓이를 돌려주는 함수 `area`를 만들고, `area(3, 4)`의 결과를 변수에 담아 출력해 보세요.

> [!question]- 예시 답안
> ```js
> function area(width, height) {
>   return width * height;
> }
> const result = area(3, 4);
> console.log(result);   // 12
> ```
