# JS 첫걸음 05 - 조건문

> **이전**: [[JS 첫걸음 04 - 연산자|04 연산자]] · **다음**: [[JS 첫걸음 06 - 반복문|06 반복문]] · **목록**: [[JS 첫걸음 00 - 로드맵|로드맵]]

## 이 레슨에서 배우는 것

1. **조건문**이 무엇이고 왜 필요한지
2. `if`, `else`, `else if`로 갈림길 만들기
3. 짧은 갈림길: **삼항 연산자** `? :`
4. 여러 갈래 갈림길: **`switch`**
5. 조건문에서 자주 하는 실수

## 1. 조건문이란?

### 비유로 이해하기: 갈림길

지금까지 만든 코드는 위에서 아래로 **한 줄로 쭉** 실행됐습니다. 언제 실행해도 똑같은 일만 했죠 (입문서 p.96: "Up to this point, our code has been rather static.").

하지만 실제 생활은 갈림길의 연속입니다.

- 비가 **오면** 우산을 챙기고, **아니면** 두고 간다.
- 점수가 90점 **이상이면** 칭찬 도장을 찍는다.
- 신호등이 초록**이면** 건너고, 노랑**이면** 조심하고, 빨강**이면** 멈춘다.

**조건문**은 코드에 이런 갈림길을 만드는 문법입니다. 조건에 따라 **이쪽 길**로 갈지 **저쪽 길**로 갈지 정합니다 (입문서 p.96: "Logical statements allow us to make multiple paths in our code.").

[[JS 첫걸음 04 - 연산자|레슨 04]]에서 배운 비교 연산자(`>`, `===`)와 논리 연산자(`&&`, `||`)가 바로 이 갈림길의 **표지판** 역할을 합니다.

## 2. `if`: 만약 …라면

### 2.1 기본 모양

```js
if (조건) {
  // 조건이 참일 때 실행할 코드
}
```

- `if` 다음 **괄호 `( )`** 안에 조건을 씁니다.
- 그다음 **중괄호 `{ }`** 안에 조건이 참일 때 할 일을 씁니다 (입문서 p.97).
- 조건이 거짓이면 `{ }` 안을 **건너뛰고** 그 아래 코드로 넘어갑니다 (입문서 p.97).

```js
let score = 95;
if (score >= 90) {
  console.log("참 잘했어요!");
}
console.log("채점 끝");
```

결과:

```
참 잘했어요!
채점 끝
```

`score`를 `70`으로 바꾸면 `score >= 90`이 거짓이 되어 첫 줄을 건너뜁니다. 결과는 `채점 끝`만 나옵니다.

### 2.2 조건 자리에 불리언이 아닌 값을 넣으면?

괄호 안의 값은 **불리언으로 바뀐 다음** 판단됩니다 (입문서 p.97: "Whatever is between these parantheses will be translated to a Boolean."). MDN은 조건을 "An expression that is considered to be either truthy or falsy."라고 설명합니다.

즉 [[JS 첫걸음 03 - 자료형|레슨 03]]의 **falsy 값 6가지**(`false`, `0`, `""`, `null`, `undefined`, `NaN`)는 거짓으로, **나머지는 전부 참**으로 봅니다.

```js
let nickname = "";
if (nickname) {
  console.log(`안녕, ${nickname}`);
} else {
  console.log("닉네임을 입력해 주세요");
}
```

결과:

```
닉네임을 입력해 주세요
```

빈 문자열 `""`은 falsy라서 `else` 쪽으로 갔습니다. 이렇게 "값이 들어 있는지"를 짧게 확인할 때 자주 씁니다.

## 3. `if...else`: 이쪽 아니면 저쪽

조건이 거짓일 때 할 일도 정하고 싶으면 **`else`** 를 붙입니다 (입문서 p.97). `else`는 "그렇지 않으면"이라는 뜻입니다.

```js
let isRaining = true;

if (isRaining) {
  console.log("우산을 챙긴다");
} else {
  console.log("우산은 두고 간다");
}
```

결과 (`isRaining`이 `true`일 때):

```
우산을 챙긴다
```

`isRaining`을 `false`로 바꾸면 `우산은 두고 간다`가 나옵니다.

**두 블록 중 정확히 하나만** 실행됩니다. 둘 다 실행되거나, 둘 다 건너뛰는 일은 없습니다 (입문서 p.97: "Only one of these two blocks will be executed").

## 4. `else if`: 갈래가 여러 개일 때

### 4.1 기본 모양

갈림길이 셋 이상이면 `else if`를 이어 붙입니다 (입문서 p.99).

```js
if (조건1) {
  // 조건1이 참일 때
} else if (조건2) {
  // 조건1은 거짓이고 조건2가 참일 때
} else {
  // 위의 조건이 모두 거짓일 때
}
```

### 4.2 예: 놀이공원 입장료

입문서의 입장료 예(p.99–100)를 원화로 바꿔 봅니다.

| 나이 | 입장료 |
|---|---|
| 3살 미만 | 무료 |
| 3살 이상 12살 미만 | 5,000원 |
| 12살 이상 65살 미만 | 10,000원 |
| 65살 이상 | 7,000원 |

```js
let age = 10;
let price;

if (age < 3) {
  price = 0;
} else if (age < 12) {
  price = 5000;
} else if (age < 65) {
  price = 10000;
} else {
  price = 7000;
}

console.log(`${age}살 입장료: ${price}원`);
```

결과:

```
10살 입장료: 5000원
```

### 4.3 위에서부터 확인하고, 처음 맞는 곳 하나만 실행

`else if` 줄은 **위에서부터 차례로** 확인합니다. **처음으로 참인 조건**을 만나면 그 블록만 실행하고, 나머지는 쳐다보지도 않습니다 (입문서 p.100: "As soon as a true expression is encountered, the other ones will be ignored.").

그래서 두 번째 조건에 `age >= 3 && age < 12`라고 쓰지 않고 `age < 12`만 써도 됩니다. 이 줄까지 왔다는 것은 이미 `age < 3`이 거짓이었다는 뜻이니까요 (입문서 p.100).

> [!warning] 순서가 중요해요
> 같은 조건이라도 **순서를 바꾸면** 결과가 달라집니다.
> ```js
> // 잘못된 순서: 넓은 조건을 먼저 씀
> if (age < 65) {
>   price = 10000;
> } else if (age < 12) {
>   price = 5000;
> } else if (age < 3) {
>   price = 0;
> }
> ```
> `age`가 2여도, 10이어도 첫 줄 `age < 65`가 참이므로 **모두 10000원**이 됩니다. 아래쪽 조건에는 영영 도착하지 못합니다. 범위를 나눌 때는 **한쪽 끝부터 차례로** 씁니다.

## 5. 삼항 연산자: 짧은 `if...else`

### 5.1 기본 모양

조건에 따라 **값 하나를 고르기만** 하면 될 때, `if...else`를 한 줄로 줄여 쓸 수 있습니다.

```js
조건 ? 참일 때 값 : 거짓일 때 값
```

입문서는 이렇게 읽으라고 합니다. `?`는 "그러면", `:`는 "아니면" (p.101: "You can read the question mark as "then" and the colon as "else" here").

```js
let age = 15;
const access = age < 18 ? "보호자 동의 필요" : "가입 가능";
console.log(access);   // 보호자 동의 필요
```

"`age < 18`이면 `"보호자 동의 필요"`, 아니면 `"가입 가능"`"으로 읽습니다.

피연산자가 **세 개**(조건, 참일 때 값, 거짓일 때 값)라서 **삼항**(三項) 연산자라고 부릅니다. MDN: "The conditional (ternary) operator is the only JavaScript operator that takes three operands". MDN은 이 연산자가 "frequently used as an alternative to an `if...else` statement"라고도 설명합니다.

```js
const n = 7;
console.log(n % 2 === 0 ? "짝수" : "홀수");   // 홀수
```

### 5.2 언제 쓰나요?

- 입문서: **아주 짧은 경우에만** 쓰고, 조건이 여러 개면 보통 `if...else`를 쓰라고 합니다 (p.101).
- 이 시리즈의 기준: **"둘 중 하나의 값을 고른다"** 일 때만 삼항 연산자를 씁니다. 무언가를 **실행**해야 하거나 갈래가 셋 이상이면 `if`를 씁니다 (판단). 삼항 연산자 안에 삼항 연산자를 또 넣으면 읽기 매우 어려워집니다.

## 6. `switch`: 하나의 값을 여러 경우와 비교

### 6.1 언제 쓰나요?

"과일이 사과면 …, 바나나면 …, 포도면 …"처럼 **값 하나를 여러 후보와 하나씩 비교**할 때는 `else if`를 길게 늘어놓는 것보다 `switch`가 읽기 쉽습니다 (입문서 p.102).

### 비유로 이해하기: 엘리베이터 층 버튼

엘리베이터는 누른 층 번호를 보고 **그 층에서** 문을 엽니다. `switch`도 값을 보고 **일치하는 `case`** 로 바로 갑니다.

### 6.2 기본 모양

```js
let fruit = "사과";

switch (fruit) {
  case "사과":
    console.log("빨간색");
    break;
  case "바나나":
    console.log("노란색");
    break;
  case "포도":
    console.log("보라색");
    break;
  default:
    console.log("모르는 과일");
}
```

결과:

```
빨간색
```

| 부분 | 뜻 |
|---|---|
| `switch (fruit)` | `fruit`의 값을 기준으로 비교한다 |
| `case "사과":` | 값이 `"사과"`이면 여기부터 실행한다 |
| `break;` | 여기서 `switch`를 빠져나간다 |
| `default:` | 어느 `case`와도 맞지 않으면 여기를 실행한다. `if`의 `else`와 비슷하다 (입문서 p.104) |

`default`는 맨 마지막에 두는 것이 약속입니다 (입문서 p.104).

### 6.3 `break`를 빠뜨리면?

`break`가 없으면 일치한 `case`부터 **아래 `case`들을 줄줄이 전부** 실행합니다 (입문서 p.103). MDN: "If break is omitted, execution will proceed to the next case clause, even to the default clause, regardless of whether the value of that clause's expression matches."

```js
let fruit = "사과";

switch (fruit) {
  case "사과":
    console.log("빨간색");
  case "바나나":
    console.log("노란색");
  case "포도":
    console.log("보라색");
  default:
    console.log("모르는 과일");
}
```

결과:

```
빨간색
노란색
보라색
모르는 과일
```

물이 아래로 흘러넘치듯 실행된다고 해서 이것을 **폴스루**(fall-through)라고 부릅니다. 대부분 실수이므로 **`case`마다 `break`를 붙이는 습관**을 들입니다.

### 6.4 일부러 `case`를 묶기

여러 값에 **같은 일**을 시키고 싶으면, `case`를 위아래로 붙여 씁니다 (입문서 p.106). 이것은 폴스루를 일부러 이용하는 방법입니다.

```js
let day = "토";
let message;

switch (day) {
  case "토":
  case "일":
    message = "주말이에요";
    break;
  case "수":
    message = "수영 가는 날";
    break;
  default:
    message = "평일이에요";
}

console.log(message);   // 주말이에요
```

`"토"`와 `"일"` 모두 `"주말이에요"`가 됩니다.

### 6.5 `switch`는 `===`로 비교합니다

`switch`는 [[JS 첫걸음 04 - 연산자|레슨 04]]의 **엄격한 같음(`===`)** 으로 비교합니다. 자료형까지 같아야 일치합니다 (입문서 p.103; MDN: "using the strict equality comparison").

```js
const input = "1";   // 문자열 "1"

switch (input) {
  case 1:            // 숫자 1
    console.log("숫자 1");
    break;
  default:
    console.log("일치하는 case 없음");
}
```

결과:

```
일치하는 case 없음
```

문자열 `"1"`과 숫자 `1`은 `===`로 비교하면 다르기 때문입니다. `switch (Number(input))`처럼 먼저 숫자로 바꾸면 `숫자 1`이 나옵니다.

## 7. 무엇을 쓸까?

| 상황 | 추천 |
|---|---|
| 조건이 하나, 참일 때만 할 일이 있음 | `if` |
| 이쪽 아니면 저쪽 | `if...else` |
| 범위로 나누기 (점수 → 학점, 나이 → 요금) | `if...else if...else` |
| 조건에 따라 **값** 둘 중 하나 고르기 | 삼항 연산자 `? :` |
| 값 하나를 여러 **정해진 값**과 비교 (요일, 메뉴 이름) | `switch` |

(판단: 입문서 p.101, p.102의 설명을 표로 정리)

`switch`는 `===` 비교만 하므로 `score >= 90` 같은 **범위 조건**에는 맞지 않습니다. 범위는 `else if`를 씁니다.

## 8. 정리

| 낱말 | 뜻 |
|---|---|
| 조건문 | 조건에 따라 실행할 코드를 고르는 문법 |
| `if (조건) { }` | 조건이 참이면 `{ }` 안을 실행 |
| `else` | 앞의 조건이 거짓일 때 실행 |
| `else if` | 앞의 조건이 거짓일 때 다른 조건을 확인. 처음 참인 곳 하나만 실행 |
| 삼항 연산자 | `조건 ? 참일 때 값 : 거짓일 때 값` |
| `switch` / `case` | 값 하나를 여러 후보와 `===`로 비교 |
| `break` | `switch`에서 빠져나가기 |
| `default` | 어느 `case`와도 맞지 않을 때 |
| 폴스루 | `break`가 없어 아래 `case`까지 이어서 실행되는 것 |

## 9. 자주 하는 실수

| 잘못 쓴 코드 | 결과 | 무엇이 문제인가 |
|---|---|---|
| `if (hobby = "coding")` (`hobby`는 `"dancing"`) | 항상 참 쪽이 실행되고, `hobby`가 `"coding"`으로 **바뀌어 버림** | `=`는 대입입니다. `"coding"`을 넣고 나면 그 값(비어 있지 않은 문자열)이 truthy라서 참이 됩니다 (입문서 p.98). 비교는 `===`. |
| `if (t > 10); { ... }` | 조건과 상관없이 `{ }` 안이 **항상** 실행됨 | `)` 뒤의 `;`이 "아무것도 하지 않는 문장"이 되어 `if`가 거기서 끝납니다. MDN: "Caution, this "if" does nothing!" (*Empty statement*) |
| `else if` 순서를 넓은 조건부터 씀 | 아래 조건에 도착하지 못함 | 4.3절 참고. 범위는 한쪽 끝부터 차례로. |
| `switch`에서 `break` 빠뜨림 | 아래 `case`까지 줄줄이 실행 | 6.3절 참고. |
| `switch ("1")`에 `case 1:` | 일치하지 않음 | `switch`는 `===`로 비교합니다. 자료형을 맞춥니다. |
| `if ("false")`가 거짓일 거라고 생각 | 참 쪽이 실행됨 | 문자열 `"false"`는 비어 있지 않으므로 truthy입니다 (레슨 03). |

## 10. 확인 퀴즈

**Q1.** `temp`가 `28`일 때 무엇이 출력될까요?
```js
if (temp >= 30) {
  console.log("너무 더워요");
} else if (temp >= 20) {
  console.log("따뜻해요");
} else {
  console.log("쌀쌀해요");
}
```

> [!question]- 정답 보기
> `따뜻해요`입니다. `28 >= 30`은 거짓, `28 >= 20`은 참이므로 두 번째 블록만 실행됩니다.

**Q2.** 아래 코드는 무엇을 출력할까요? `if`가 따로따로인 경우와 `else if`로 이어진 경우를 비교해 보세요.
```js
let x = 10;
if (x > 5) { console.log("A"); }
if (x > 8) { console.log("B"); }

if (x > 5) { console.log("C"); }
else if (x > 8) { console.log("D"); }
```

> [!question]- 정답 보기
> `A`, `B`, `C`가 출력됩니다.
> - 위쪽 두 `if`는 **서로 다른 갈림길**이라 각각 확인합니다. 둘 다 참이라 `A`와 `B`가 모두 나옵니다.
> - 아래쪽은 **하나의 갈림길**이라 처음 참인 `C`만 실행하고 `D`는 확인하지 않습니다.

**Q3.** 점수(`score`)에 따라 학점을 정하는 코드를 `if...else if...else`로 쓰세요. 90점 이상 `"A"`, 80점 이상 `"B"`, 70점 이상 `"C"`, 나머지 `"F"`.

> [!question]- 정답 보기
> ```js
> let grade;
> if (score >= 90) {
>   grade = "A";
> } else if (score >= 80) {
>   grade = "B";
> } else if (score >= 70) {
>   grade = "C";
> } else {
>   grade = "F";
> }
> ```
> `score`가 85면 `"B"`, 50이면 `"F"`입니다. 높은 점수부터 차례로 확인합니다.

**Q4.** `light`가 `"노랑"`일 때 무엇이 출력될까요?
```js
switch (light) {
  case "초록":
    console.log("건너요");
    break;
  case "노랑":
    console.log("조심해요");
  case "빨강":
    console.log("멈춰요");
    break;
}
```

> [!question]- 정답 보기
> `조심해요`와 `멈춰요`가 둘 다 출력됩니다. `"노랑"` case에 `break`가 없어서 `"빨강"` case까지 이어서 실행됩니다.

**Q5.** 아래 `if...else`를 삼항 연산자 한 줄로 바꾸세요.
```js
let result;
if (score >= 60) {
  result = "합격";
} else {
  result = "불합격";
}
```

> [!question]- 정답 보기
> ```js
> const result = score >= 60 ? "합격" : "불합격";
> ```

**Q6.** 입문서 퀴즈 2번(p.109)입니다. 무엇이 출력될까요?
```js
const q = 1;
let answer;
switch (q) {
  case '1':
    answer = "one";
  case 1:
    answer = 1;
  case 2:
    answer = "this is the one";
    break;
  default:
    answer = "not working";
}
console.log(answer);
```

> [!question]- 정답 보기
> `this is the one`입니다.
> 1. `q`는 숫자 `1`이라 문자열 `'1'`과는 일치하지 않습니다 (`===` 비교).
> 2. `case 1`과 일치해 `answer = 1`을 실행합니다.
> 3. `break`가 없어서 `case 2`로 흘러가 `answer = "this is the one"`으로 덮어씁니다.
> 4. 거기서 `break`를 만나 빠져나옵니다.

**Q7. (직접 해 보기)** 변수 `menu`에 `"짜장"`, `"짬뽕"`, `"탕수육"` 중 하나를 넣고, `switch`로 가격을 출력해 보세요. 짜장 7000원, 짬뽕 8000원, 탕수육 18000원, 그 밖에는 `"없는 메뉴예요"`.

> [!question]- 예시 답안
> ```js
> const menu = "짬뽕";
> switch (menu) {
>   case "짜장":
>     console.log("7000원");
>     break;
>   case "짬뽕":
>     console.log("8000원");
>     break;
>   case "탕수육":
>     console.log("18000원");
>     break;
>   default:
>     console.log("없는 메뉴예요");
> }
> // 8000원
> ```
