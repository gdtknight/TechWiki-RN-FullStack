## 1. 반복문이란?

### 비유로 이해하기: 줄넘기 100번

선생님이 "줄넘기 100번!"이라고 하면, "줄넘기 1번, 줄넘기 1번, 줄넘기 1번…"을 100번 따로 말하지 않습니다. **"100번이 될 때까지 계속 넘어"** 라고 한 번만 말하죠.

**반복문**(loop)은 같은 일을 여러 번 시키는 문법입니다 (입문서 p.112: "Loops execute a code block a certain number of times."). 입문서는 이렇게 조언합니다. 코드를 복사해서 바로 아래에 붙여 넣고 싶어질 때가 있다면, 그때가 반복문을 써야 할 때라는 것입니다 (p.112).

```js
// 반복문 없이: 5줄을 일일이 씀
console.log("줄넘기!");
console.log("줄넘기!");
console.log("줄넘기!");
console.log("줄넘기!");
console.log("줄넘기!");
```

100번이라면 100줄을 써야 합니다. 반복문을 쓰면 몇 번이든 **세 줄**이면 됩니다. 아래에서 하나씩 배웁니다.

### 반복문의 세 가지 재료

어떤 반복문이든 다음 세 가지가 있습니다 (판단: 입문서 p.113–118의 예를 정리).

| 재료 | 줄넘기에 비유하면 | 코드에서 |
|---|---|---|
| ① 시작 | "0번부터 센다" | `let i = 0` |
| ② 계속할 조건 | "100번이 안 됐으면 계속" | `i < 100` |
| ③ 한 번 할 때마다 바뀌는 것 | "한 번 넘으면 숫자를 하나 올린다" | `i++` |

③을 빠뜨리면 숫자가 영원히 바뀌지 않아서 **영원히 반복**합니다. 7절에서 자세히 봅니다.

## 2. `while`: 조건이 참인 동안

### 2.1 기본 모양

```js
while (조건) {
  // 조건이 참인 동안 반복할 코드
}
```

`while`은 "…하는 동안"이라는 뜻입니다. **조건을 먼저 확인**하고, 참이면 `{ }` 안을 실행한 뒤 다시 조건을 확인합니다. 거짓이 되면 멈춥니다 (MDN: "The `while` statement creates a loop that executes a specified statement as long as the test condition evaluates to true." / "The condition is evaluated before executing the statement.").

### 2.2 예: 로켓 발사 카운트다운

```js
let count = 3;
while (count > 0) {
  console.log(count);
  count--;
}
console.log("발사!");
```

결과:

```
3
2
1
발사!
```

한 바퀴씩 따라가 봅니다.

| 바퀴 | `count` | `count > 0` | 하는 일 |
|---|---|---|---|
| 1 | 3 | 참 | `3` 출력, `count`를 2로 |
| 2 | 2 | 참 | `2` 출력, `count`를 1로 |
| 3 | 1 | 참 | `1` 출력, `count`를 0으로 |
| 4 | 0 | **거짓** | 반복 끝 → 아래의 `발사!` 출력 |

### 2.3 처음부터 조건이 거짓이면?

`while`은 조건을 **먼저** 확인하므로, 처음부터 거짓이면 `{ }` 안을 **한 번도** 실행하지 않습니다 (입문서 p.113).

```js
let n = 10;
while (n < 5) {
  console.log("실행 안 됨");
}
console.log("끝");
```

결과:

```
끝
```

## 3. `do...while`: 일단 한 번은 한다

### 3.1 기본 모양

```js
do {
  // 먼저 한 번 실행하고, 조건이 참이면 다시 반복할 코드
} while (조건);
```

`while`과 반대로 **실행부터 하고 나서** 조건을 확인합니다. 그래서 조건이 처음부터 거짓이어도 **최소 한 번은** 실행됩니다. MDN: "The condition is evaluated after executing the statement, resulting in the specified statement executing at least once."

```js
let k = 10;
do {
  console.log(`k는 ${k}`);
  k++;
} while (k < 5);
```

결과:

```
k는 10
```

`k < 5`는 처음부터 거짓이지만, 조건을 확인하기 전에 이미 한 번 실행했습니다.

### 3.2 언제 쓰나요?

**일단 한 번 해 봐야 하는 일**에 씁니다. 입문서는 사용자에게 입력을 받는 경우를 예로 듭니다. 적어도 한 번은 물어봐야 하고, 올바른 값이 들어올 때까지 다시 물어봅니다 (p.116).

### 비유로 이해하기: 맛보기

음식 간을 볼 때는 **일단 한 번 맛을 보고**, 싱거우면 소금을 넣고 다시 맛봅니다. 맛을 보기도 전에 "싱거우면"을 확인할 수는 없죠 (판단).

> 입문서의 문법 모양처럼 `} while (조건);` 끝에 **세미콜론 `;`** 을 붙입니다 (입문서 p.116). 다른 문장 끝에 세미콜론을 붙이는 습관(레슨 01)과 같습니다.

## 4. `for`: 정해진 횟수만큼

### 4.1 기본 모양

반복 횟수가 정해져 있을 때 가장 많이 쓰는 반복문입니다. 1절의 **세 가지 재료를 괄호 안에 한꺼번에** 씁니다.

```js
for (시작; 계속할 조건; 한 번 끝날 때마다) {
  // 반복할 코드
}
```

세 부분은 **세미콜론 `;`** 으로 나눕니다 (입문서 p.118). MDN의 설명:

| 부분 | 언제 실행되나 | MDN |
|---|---|---|
| 시작 (initialization) | 반복을 시작하기 전에 **딱 한 번** | "evaluated once before the loop begins" |
| 조건 (condition) | 매번 반복하기 **전에** | "An expression to be evaluated before each loop iteration." |
| 바뀌는 것 (afterthought) | 매번 반복이 **끝날 때** | "An expression to be evaluated at the end of each loop iteration." |

### 4.2 예: 줄넘기 5번

```js
for (let i = 1; i <= 5; i++) {
  console.log(`${i}번째 줄넘기`);
}
```

결과:

```
1번째 줄넘기
2번째 줄넘기
3번째 줄넘기
4번째 줄넘기
5번째 줄넘기
```

순서는 이렇습니다 (입문서 p.118).

1. `let i = 1`: `i`를 1로 시작합니다. **한 번만** 합니다.
2. `i <= 5`인지 확인합니다. 참이면 3번으로, 거짓이면 반복을 끝냅니다.
3. `{ }` 안을 실행합니다.
4. `i++`로 `i`를 1 올립니다.
5. 2번으로 돌아갑니다.

> [!tip] 왜 `i`라는 이름을 쓰나요?
> 반복 횟수를 세는 변수는 관례로 `i`라고 짓습니다. 입문서의 예제도 모두 `i`를 씁니다. index(순서 번호)의 머리글자로 흔히 설명합니다 (판단). 레슨 02에서 "이름은 뜻이 드러나게"라고 했지만, 반복 횟수를 세는 `i`만은 짧게 쓰는 것이 널리 쓰이는 예외입니다.

### 4.3 다양하게 세기

세 번째 부분에는 `i++`가 아닌 다른 식도 쓸 수 있습니다 (입문서 p.119).

```js
// 2씩 올리기: 짝수만
for (let i = 0; i <= 10; i += 2) {
  console.log(i);   // 0 2 4 6 8 10
}

// 거꾸로 세기
for (let i = 10; i >= 0; i -= 5) {
  console.log(i);   // 10 5 0
}
```

### 4.4 예: 1부터 100까지 더하기

반복문과 변수를 함께 쓰면 계산을 차곡차곡 쌓을 수 있습니다.

```js
let sum = 0;
for (let i = 1; i <= 100; i++) {
  sum += i;
}
console.log(sum);   // 5050
```

`sum`은 0에서 시작해 매번 `i`를 더합니다. 0+1, 1+2, 3+3, 6+4 … 이렇게 100번 더하면 `5050`이 됩니다.

### 4.5 `for` 안에서 만든 `let`은 밖에서 안 보여요

```js
for (let i = 0; i < 3; i++) {}
console.log(i);
```

결과:

```
ReferenceError: i is not defined
```

MDN: "Variables declared with `let` are local to the statement." [[JS 첫걸음 02 - 변수|레슨 02]]의 블록 스코프와 같은 이야기입니다. 덕분에 다른 곳에서 또 `for (let i = …)`를 써도 서로 부딪히지 않습니다.

## 5. `break`와 `continue`

### 5.1 `break`: 반복을 즉시 끝낸다

[[JS 첫걸음 05 - 조건문|레슨 05]]의 `switch`에서 본 `break`는 반복문에서도 씁니다. 만나는 즉시 **반복 전체를 끝내고** 반복문 아래로 넘어갑니다 (입문서 p.133). MDN: "The `break` statement terminates the current loop or `switch` statement".

```js
for (let i = 0; i < 10; i++) {
  console.log(i);
  if (i === 4) {
    break;
  }
}
```

결과:

```
0
1
2
3
4
```

0부터 9까지 셀 것처럼 생겼지만, `i`가 4일 때 `break`를 만나 거기서 끝납니다 (입문서 p.133의 예).

**언제 쓰나요?** 원하는 것을 **찾았으니 더 볼 필요가 없을 때** 씁니다. 입문서는 조건에 맞는 자동차를 찾으면 나머지는 보지 않는 예를 듭니다 (p.133).

### 5.2 `continue`: 이번 바퀴만 건너뛴다

`continue`는 반복을 끝내지 않고, **이번 바퀴의 나머지만 건너뛰고** 다음 바퀴로 갑니다 (입문서 p.134). MDN: "In contrast to the break statement, `continue` does not terminate the execution of the loop entirely".

```js
// 1부터 10까지 중 홀수만 출력
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) {
    continue;   // 짝수면 아래 console.log를 건너뜀
  }
  console.log(i);
}
```

결과:

```
1
3
5
7
9
```

### 비유로 이해하기: 급식 줄

| | 비유 |
|---|---|
| `break` | 급식 줄에 서 있다가 **줄에서 아예 나간다** |
| `continue` | 싫어하는 반찬 **한 칸만 건너뛰고** 다음 반찬 칸으로 간다 |

### 5.3 더 간단한 방법이 있으면 그걸 쓰세요

입문서는 `break`와 `continue`를 남용하지 말라고 합니다. 반복을 언제 멈출지는 **조건 자리에 드러내는 것**이 읽기 쉽다는 이유입니다 (p.133–134). 위의 홀수 예도 `continue` 없이 더 짧게 쓸 수 있습니다 (입문서 p.136).

```js
for (let i = 1; i < 10; i += 2) {
  console.log(i);   // 1 3 5 7 9
}
```

## 6. 반복문 안의 반복문

### 6.1 예: 구구단

반복문 안에 또 반복문을 넣을 수 있습니다. 이것을 **중첩 반복문**(nested loop)이라고 합니다 (입문서 p.120).

먼저 2단 하나만 출력해 봅니다.

```js
for (let i = 1; i <= 9; i++) {
  console.log(`2 x ${i} = ${2 * i}`);
}
```

이제 2단부터 3단까지 출력하려면, **단을 바꾸는 반복**을 바깥에 하나 더 씌웁니다. 여기서는 짧게 각 단의 1–3만 출력합니다.

```js
for (let dan = 2; dan <= 3; dan++) {        // 바깥: 단 (2, 3)
  for (let i = 1; i <= 3; i++) {            // 안쪽: 곱하는 수 (1, 2, 3)
    console.log(`${dan} x ${i} = ${dan * i}`);
  }
}
```

결과:

```
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
```

**바깥 반복이 한 번 돌 때마다 안쪽 반복은 처음부터 끝까지** 돕니다. 시계에 비유하면 바깥 반복은 시침, 안쪽 반복은 분침입니다. 분침이 한 바퀴 돌아야 시침이 한 칸 움직입니다 (판단).

### 6.2 예: 별 계단

```js
for (let row = 1; row <= 4; row++) {
  let line = "";
  for (let col = 1; col <= row; col++) {
    line += "*";
  }
  console.log(line);
}
```

결과:

```
*
**
***
****
```

안쪽 반복의 조건이 `col <= row`라서, 바깥의 `row`가 커질수록 별이 하나씩 늘어납니다.

### 6.3 중첩 반복에서 `break`는 안쪽만 끝냅니다

안쪽 반복에서 `break`를 쓰면 **안쪽 반복만** 끝나고, 바깥 반복은 계속 돕니다 (입문서 p.136: "the outer loop will not break").

```js
for (let a = 1; a <= 3; a++) {
  for (let b = 1; b <= 3; b++) {
    if (b === 2) {
      break;
    }
    console.log(a, b);
  }
}
```

결과:

```
1 1
2 1
3 1
```

바깥까지 한 번에 끝내는 방법(레이블)도 있지만, 입문 단계에서는 쓰지 않아도 됩니다 (입문서 p.138–139).

## 7. 무한 루프 조심하기

### 7.1 무한 루프란?

조건이 **영원히 참**이면 반복이 끝나지 않습니다. 이것을 **무한 루프**(infinite loop)라고 합니다 (입문서 p.114, p.118).

```js
let i = 0;
while (i < 10) {
  console.log(i);
  // i++를 빠뜨림 → i는 영원히 0 → 영원히 반복
}
```

입문서도 "이것은 모든 반복문에서 조심해야 한다(This is something to look out for in all loops!)"고 강조합니다 (p.118).

> [!warning] 콘솔에서 무한 루프가 돌면
> 그 탭이 멈춰서 아무것도 클릭되지 않을 수 있습니다. 당황하지 말고 **탭을 닫은 뒤 새로 여세요** (판단). 저장하지 않은 작업이 있는 탭에서는 연습하지 마세요.

### 7.2 무한 루프가 생기는 흔한 경우

| 원인 | 예 | 고치는 법 |
|---|---|---|
| 바뀌는 것(③)을 빠뜨림 | `while (i < 10) { console.log(i); }` | `i++`를 넣는다 |
| 잘못된 방향으로 바꿈 | `for (let i = 0; i < 10; i--)` | 커져야 하는데 작아짐. `i++`로 |
| `while` 안에서 `continue`가 `i++`보다 먼저 | 아래 예 | `i++`를 `continue` 위로 옮기거나 `for`를 쓴다 |

세 번째 경우는 입문서가 직접 보여 주는 함정입니다 (p.135).

```js
// 홀수만 출력하려고 했지만…
let i = 1;
while (i < 50) {
  if (i % 2 === 0) {
    continue;   // i가 2일 때 여기서 위로 돌아감 → i++에 영영 도착하지 못함
  }
  console.log(i);
  i++;
}
```

`1`을 출력한 뒤 `i`가 2가 되면, `continue`가 `i++`보다 먼저 실행되어 `i`가 영원히 2에 머뭅니다. Node.js에서 실행해 보면 `1`만 출력하고 끝나지 않습니다. `for`문은 `i++`를 괄호 안에 두기 때문에 이 실수가 생기지 않습니다 (판단).

## 8. 무엇을 쓸까?

| 상황 | 추천 |
|---|---|
| 몇 번 반복할지 정해져 있음 (5번, 1–100) | `for` |
| 언제 끝날지 모르고, 조건이 될 때까지 (목표 점수가 될 때까지) | `while` |
| 일단 한 번은 해야 함 (입력 받기) | `do...while` |

(판단: 입문서 p.113, p.116, p.118의 설명을 표로 정리)

> [!note] 미리 보기: `for...of`와 `for...in`
> 입문서 Ch 5에는 배열과 객체를 반복하는 `for...of`(p.126)와 `for...in`(p.128)도 나옵니다. 배열과 객체를 먼저 알아야 이해할 수 있으므로 레슨 08(배열)과 09(객체)에서 배웁니다.

---

## 9. 정리

| 낱말 | 뜻 |
|---|---|
| 반복문 (loop) | 같은 코드를 여러 번 실행하는 문법 |
| `while` | 조건을 **먼저** 확인하고, 참인 동안 반복. 처음부터 거짓이면 0번 |
| `do...while` | **먼저 한 번** 실행하고 조건 확인. 최소 1번 |
| `for (시작; 조건; 바뀌는 것)` | 횟수가 정해진 반복. 세 부분을 `;`로 나눔 |
| `break` | 반복 전체를 즉시 끝냄 |
| `continue` | 이번 바퀴만 건너뛰고 다음 바퀴로 |
| 중첩 반복문 | 반복문 안의 반복문. 바깥 한 번에 안쪽 전체 |
| 무한 루프 | 조건이 영원히 참이라 끝나지 않는 반복 |

## 10. 자주 하는 실수

| 잘못 쓴 코드 | 결과 | 무엇이 문제인가 |
|---|---|---|
| `while (i < 10) { console.log(i); }` | 무한 루프 | `i`를 바꾸는 코드(`i++`)가 없습니다. |
| `for (let i = 0; i < 10; i--)` | 무한 루프 | `i`가 작아지기만 해서 `i < 10`이 영원히 참입니다. |
| `for (let i = 0, i < 5, i++)` | `SyntaxError: Identifier 'i' has already been declared` | `for` 괄호 안은 쉼표가 아니라 **세미콜론**으로 나눕니다. 쉼표로 쓰면 엔진이 `let i = 0, i …`를 "변수를 여러 개 만드는 한 문장"으로 읽어서 `i`를 두 번 만든다고 보는 것으로 보입니다 (판단: 에러 메시지로 추론). |
| `for (let i = 1; i < 5; i++)`로 1–5를 세려 함 | 1, 2, 3, 4까지만 | 5를 포함하려면 `i <= 5`. "미만"과 "이하"를 구별합니다. |
| `for` 다음에 `console.log(i)` | `ReferenceError: i is not defined` | `for (let i …)`의 `i`는 반복문 안에서만 보입니다. |
| `while` 안에서 `continue`를 `i++`보다 위에 둠 | 무한 루프 | 7.2절 참고. |

## 11. 확인 퀴즈

**Q1.** 아래 코드는 무엇을 출력할까요? (입문서 퀴즈 1, p.140)
```js
let step = 3;
for (let i = 0; i < 1000; i += step) {
  if (i > 10) {
    break;
  }
  console.log(i);
}
```

> [!question]- 정답 보기
> `0`, `3`, `6`, `9`입니다. `i`가 3씩 커지다가 12가 되면 `i > 10`이 참이 되어 `break`로 끝납니다. 12는 출력되기 전에 끝납니다.

**Q2.** 아래 코드가 끝나면 `total`은 얼마일까요?
```js
let total = 0;
for (let i = 0; i < 5; i++) {
  total += 2;
}
```

> [!question]- 정답 보기
> `10`입니다. `i`가 0, 1, 2, 3, 4일 때 다섯 번 2를 더합니다.

**Q3.** 아래 코드는 무엇을 출력할까요?
```js
let t = 1;
while (t < 100) {
  t *= 2;
}
console.log(t);
```

> [!question]- 정답 보기
> `128`입니다. `t`는 1 → 2 → 4 → 8 → 16 → 32 → 64 → 128로 커집니다. 64일 때는 `64 < 100`이 참이라 한 번 더 곱해 128이 되고, `128 < 100`이 거짓이라 멈춥니다.

**Q4.** `while`과 `do...while`의 가장 큰 차이는 무엇일까요?

> [!question]- 정답 보기
> 조건을 확인하는 **시점**입니다. `while`은 실행 **전에** 확인해서 0번 실행될 수도 있고, `do...while`은 실행 **후에** 확인해서 최소 1번은 실행됩니다.

**Q5.** 1부터 20까지 중 **3의 배수가 몇 개인지** 세는 코드를 쓰세요. (힌트: 레슨 04의 `%`)

> [!question]- 정답 보기
> ```js
> let count = 0;
> for (let i = 1; i <= 20; i++) {
>   if (i % 3 === 0) {
>     count++;
>   }
> }
> console.log(count);   // 6  (3, 6, 9, 12, 15, 18)
> ```

**Q6.** 아래 코드는 왜 끝나지 않을까요?
```js
let i = 0;
while (i < 5) {
  console.log("안녕");
}
```

> [!question]- 정답 보기
> 반복 안에서 `i`를 바꾸지 않아서 `i < 5`가 영원히 참이기 때문입니다. `{ }` 안에 `i++;`를 넣으면 다섯 번 출력하고 끝납니다.

**Q7. (직접 해 보기)** 콘솔에서 **5단** 구구단 전체(5 x 1 = 5부터 5 x 9 = 45까지)를 출력해 보세요.

> [!question]- 예시 답안
> ```js
> for (let i = 1; i <= 9; i++) {
>   console.log(`5 x ${i} = ${5 * i}`);
> }
> ```

**Q8. (도전)** 6.1절의 코드를 고쳐서 **2단부터 9단까지 전체 구구단**을 출력해 보세요.

> [!question]- 예시 답안
> ```js
> for (let dan = 2; dan <= 9; dan++) {
>   for (let i = 1; i <= 9; i++) {
>     console.log(`${dan} x ${i} = ${dan * i}`);
>   }
> }
> ```
> 8 × 9 = 72줄이 출력됩니다.
