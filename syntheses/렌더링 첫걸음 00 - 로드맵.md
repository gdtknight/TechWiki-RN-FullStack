# 렌더링 첫걸음 00 - 로드맵

> [[JS 첫걸음 00 - 로드맵|JS 첫걸음]] 시리즈 다음 단계의 레슨 시리즈입니다. **브라우저가 화면을 그리는 원리**에서 출발해, **React 컴포넌트의 생명 주기와 Effect**, 그리고 **React Native 앱과 화면의 생명 주기**까지 하나로 이어 봅니다.
> 각 레슨은 JS 첫걸음과 같은 순서(**비유 → 직접 해 보기 → 정리 → 자주 하는 실수 → 퀴즈**)에, 위키 개념 페이지 수준의 **"더 깊이" 절**을 더했습니다. 처음 읽을 때는 "더 깊이" 절을 건너뛰어도 됩니다.

---

## 질문 / 문제 의식

- `useEffect`는 **언제** 실행될까요? "화면이 그려진 다음"이라고 하는데, 화면은 **누가, 어떻게** 그릴까요?
- 웹에서 잘 되던 코드가 React Native 앱에서는 왜 화면을 떠나도 정리되지 않을까요?
- 이 질문에 답하려면 **브라우저 → React → React Native** 순서로, 아래 계층부터 이해해야 합니다.

```
┌──────────────────────────────────────────┐
│ 레슨 07–08  React Native: 네이티브 뷰, 앱·화면 생명 주기 │
├──────────────────────────────────────────┤
│ 레슨 03–06  React: 렌더 → 커밋 → Effect          │
├──────────────────────────────────────────┤
│ 레슨 01–02  브라우저: 파싱 → 레이아웃 → 페인트, 프레임 │
└──────────────────────────────────────────┘
          레슨 09  종합: 버튼 하나를 누르면
```

---

## 시작하기 전에

- [[JS 첫걸음 00 - 로드맵|JS 첫걸음]] 레슨 07(함수), 09(객체), 10(클로저), 11(비동기 기초)을 알면 충분합니다.
- React를 처음 만나도 괜찮습니다. 레슨 03에서 필요한 만큼만 배웁니다.
- 레슨 01–02의 "직접 해 보기"는 **브라우저 콘솔**에서 합니다 ([[JS 첫걸음 01 - 프로그램과 콘솔|JS 첫걸음 01]]).
- 레슨 03–06의 React 예제는 React 19.3.1 + react-dom + jsdom 환경에서 실행해 결과를 확인했습니다. jsdom에는 **화면 그리기(페인트)가 없으므로**, 페인트와의 순서는 공식 문서를 근거로 씁니다.
- 레슨 07–08의 React Native 예제는 앱 실행 환경이 없어 실행하지 못했습니다. 공식 문서를 근거로 쓰고, 그렇게 표시합니다.
