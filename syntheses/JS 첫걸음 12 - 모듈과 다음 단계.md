## 1. 파일로 실행하기

지금까지는 브라우저 콘솔에 한 줄씩 입력했습니다. 코드가 길어지면 **파일에 저장해 두고 실행**하는 것이 편합니다.

컴퓨터에 **Node.js**(브라우저 밖에서 JavaScript를 실행하는 프로그램)가 설치되어 있으면, 터미널에서 이렇게 실행합니다 (판단: 이 시리즈의 모든 예제를 이 방법으로 확인함).

```bash
node hello.js
```

`hello.js` 안에 `console.log("안녕!");`이 들어 있으면 터미널에 `안녕!`이 출력됩니다. 입문서도 [[JS 첫걸음 01 - 프로그램과 콘솔|레슨 01]]에서 본 것처럼 HTML 파일에 JavaScript 파일을 연결해 실행하는 방법(p.34–35)과, Node.js로 서버 쪽 코드를 실행하는 방법(p.440–445)을 소개합니다.

## 2. 모듈이란?

### 비유로 이해하기: 레고 상자 정리함

레고 조각을 큰 상자 하나에 전부 쏟아 두면, 필요한 조각을 찾기 어렵습니다. 바퀴는 바퀴 칸에, 창문은 창문 칸에 나눠 두면 필요한 칸에서 꺼내 쓰기 쉽습니다.

코드도 마찬가지입니다. 수천 줄을 파일 하나에 다 쓰면 찾기도, 고치기도 어렵습니다. **역할별로 파일을 나누고**, 필요한 파일에서 필요한 것만 가져다 씁니다. 이렇게 나눈 파일 하나하나를 **모듈**(module)이라고 합니다.

MDN: "Complex projects necessitate a mechanism for splitting JavaScript programs into separate modules that can be imported when needed."

[[React]]와 [[React Native]] 앱은 화면 하나, 기능 하나마다 파일을 나누고 서로 `import`해서 만듭니다. 앱 코드를 열면 거의 모든 파일의 첫 줄이 `import`입니다 (판단).

## 3. 내보내기와 가져오기

### 3.1 `export`: 이 파일 밖에서도 쓰게 내보내기

`math.mjs` 파일을 만듭니다.

```js
// math.mjs
export const PI = 3.14159;

export function add(a, b) {
  return a + b;
}

export function circleArea(r) {
  return PI * r * r;
}

const secret = "모듈 밖에서는 안 보여요";   // export를 안 붙임
```

앞에 **`export`** 를 붙인 것만 다른 파일에서 가져다 쓸 수 있습니다. `secret`처럼 `export`가 없는 것은 **이 파일 안에서만** 보입니다. MDN: "Module-defined variables are scoped to the module unless explicitly attached to the global object." [[JS 첫걸음 10 - 스코프와 클로저|레슨 10]]의 스코프가 **파일 단위**로도 있는 셈입니다 (MDN *Scope*: "Module scope: The scope for code running in module mode.").

### 3.2 `import`: 다른 파일에서 가져오기

같은 폴더에 `main.mjs`를 만듭니다.

```js
// main.mjs
import { add, circleArea } from "./math.mjs";

console.log(add(2, 3));        // 5
console.log(circleArea(2));    // 12.56636
```

```bash
node main.mjs
```

| 부분 | 뜻 |
|---|---|
| `import { add, circleArea }` | 이 이름들을 가져오겠다 |
| `from "./math.mjs"` | 이 파일에서 |
| `./` | "지금 이 파일이 있는 폴더"라는 뜻 (MDN: "using the dot (`.`) syntax to mean "the current location"") |

> [!note] 왜 `.js`가 아니라 `.mjs`예요?
> Node.js에게 "이 파일은 모듈이야"라고 알려 주는 방법 중 하나입니다. Node.js 공식 문서: "Authors can tell Node.js to interpret JavaScript as an ES module via the `.mjs` file extension, the `package.json` `"type"` field with a value `"module"`, or the `--input-type` flag with a value of `"module"`." 실제 프로젝트에서는 보통 `package.json`에 설정하거나, React Native·Expo 같은 도구가 알아서 처리해 줍니다 (판단). 브라우저에서는 `<script type="module">`로 모듈임을 알립니다 (MDN: "you need to include `type="module"` in the `<script>` element").

## 4. 이름 붙은 내보내기와 기본 내보내기

내보내는 방법은 두 가지입니다. MDN *export*: "Every module can have two different types of export, named export and default export. You can have multiple named exports per module but only one default export."

### 4.1 이름 붙은 내보내기 (named export)

3절에서 본 방법입니다. 한 파일에서 **여러 개**를 내보낼 수 있고, 가져올 때는 **중괄호 `{ }`** 안에 **같은 이름**을 씁니다.

```js
import { add, PI } from "./math.mjs";
```

이름을 바꿔서 가져오고 싶으면 `as`를 씁니다.

```js
import { add as plus } from "./math.mjs";
console.log(plus(10, 20));   // 30
```

### 4.2 기본 내보내기 (default export)

파일의 **대표** 하나를 내보낼 때 씁니다. 파일 하나에 **하나만** 있을 수 있습니다.

```js
// greet.mjs
export default function greet(name) {
  return `안녕, ${name}!`;
}
```

가져올 때는 **중괄호 없이**, 그리고 **아무 이름으로나** 받을 수 있습니다.

```js
import greet from "./greet.mjs";
import sayHello from "./greet.mjs";   // 다른 이름으로 받아도 같은 함수

console.log(greet("민수"));     // 안녕, 민수!
console.log(sayHello("지수"));  // 안녕, 지수!
```

MDN *export*: "named exports must be referred to by the exact same name (optionally renaming it with `as`), but the default export can be imported with any name."

### 4.3 한눈에 비교

| | 이름 붙은 내보내기 | 기본 내보내기 |
|---|---|---|
| 내보내기 | `export function add() {}` | `export default function greet() {}` |
| 파일당 개수 | 여러 개 | **하나** |
| 가져오기 | `import { add } from "…"` | `import greet from "…"` |
| 중괄호 | **필요** | **없음** |
| 이름 | 같은 이름 (또는 `as`) | 아무 이름 |

React Native 앱에서는 화면 하나를 기본 내보내기로, 여러 도우미 함수를 이름 붙은 내보내기로 내보내는 모양을 자주 봅니다 (판단).

### 4.4 맛보기: 모듈 최상위의 `await`

[[JS 첫걸음 11 - 비동기 기초|레슨 11]]에서 `await`는 `async` 함수 안에서만 쓴다고 했습니다. 모듈에서는 **함수 밖 최상위**에서도 쓸 수 있습니다. MDN *await*: "It can only be used inside an async function or at the top level of a module."

```js
// main.mjs
const data = await Promise.resolve("모듈 최상위 await");
console.log(data);   // 모듈 최상위 await
```

## 5. 모듈은 처음부터 엄격 모드

[[JS 첫걸음 10 - 스코프와 클로저|레슨 10]]의 5절에서 `let`/`const` 없이 대입하면 전역 변수가 생기는 문제를 봤습니다. 모듈 안에서는 이것이 **처음부터 에러**입니다. MDN: "modules use strict mode automatically."

```js
// strict.mjs
oops = 1;   // ❌ ReferenceError: oops is not defined
```

## 6. 정리

| 낱말 | 뜻 |
|---|---|
| Node.js | 브라우저 밖에서 JavaScript를 실행하는 프로그램. `node 파일이름` |
| 모듈 | 역할별로 나눈 JavaScript 파일 하나 |
| `export` | 다른 파일에서 쓰도록 내보내기 |
| `import … from "…"` | 다른 파일에서 가져오기 |
| `./` | 지금 파일이 있는 폴더 |
| 이름 붙은 내보내기 | 여러 개 가능. `import { 이름 }` |
| 기본 내보내기 | 파일당 하나. `import 아무이름` |
| `as` | 가져올 때 이름 바꾸기 |
| 모듈 스코프 | `export`하지 않은 것은 그 파일 안에서만 보임 |

## 7. 자주 하는 실수

| 잘못 쓴 코드 | 결과 (Node.js v24.19.0) | 무엇이 문제인가 |
|---|---|---|
| `import { sum } from "./math.mjs";` (`sum`은 없음) | `SyntaxError: The requested module './math.mjs' does not provide an export named 'sum'` | 내보낸 이름과 똑같이 써야 합니다. 오타나 대소문자를 확인합니다. |
| `import { greet } from "./greet.mjs";` (기본 내보내기인데 중괄호) | `SyntaxError: The requested module './greet.mjs' does not provide an export named 'greet'` | 기본 내보내기는 중괄호 없이 `import greet from …`. |
| `import { add } from "math.mjs";` (`./` 없음) | `Error [ERR_MODULE_NOT_FOUND]: Cannot find package 'math.mjs' …` | `./`가 없으면 내 파일이 아니라 **설치한 패키지** 이름으로 찾습니다. 내 파일은 `./`로 시작합니다. |
| 다른 파일의 `export` 안 한 변수를 가져오려 함 | 위 첫 번째와 같은 에러 | `export`를 붙인 것만 가져올 수 있습니다. |

## 8. 확인 퀴즈

**Q1.** 아래 `shapes.mjs`에서 `square`만 가져오는 `import` 문을 쓰세요.
```js
export function square(n) { return n * n; }
export function cube(n) { return n * n * n; }
```

> [!question]- 정답 보기
> ```js
> import { square } from "./shapes.mjs";
> ```

**Q2.** 이름 붙은 내보내기와 기본 내보내기를 가져올 때 가장 눈에 띄는 차이는?

> [!question]- 정답 보기
> 중괄호입니다. 이름 붙은 내보내기는 `import { 이름 }`처럼 중괄호와 **같은 이름**이 필요하고, 기본 내보내기는 `import 아무이름`처럼 중괄호 없이 원하는 이름으로 받습니다.

**Q3.** 한 파일에 `export default`를 두 번 쓸 수 있을까요?

> [!question]- 정답 보기
> 없습니다. 기본 내보내기는 파일당 하나만 있을 수 있습니다 (MDN: "only one default export").

**Q4.** 아래 모듈에서 다른 파일이 가져올 수 **없는** 것은?
```js
export const name = "앱";
const version = 2;
export function start() {}
```

> [!question]- 정답 보기
> `version`입니다. `export`가 없으므로 이 파일 안에서만 보입니다.

**Q5. (직접 해 보기)** 컴퓨터에 Node.js가 있다면 3절의 `math.mjs`와 `main.mjs`를 같은 폴더에 만들고 `node main.mjs`로 실행해 보세요. `math.mjs`에 `export function subtract(a, b)`를 추가하고 `main.mjs`에서 가져와 써 보세요.

> [!question]- 예시 답안
> ```js
> // math.mjs에 추가
> export function subtract(a, b) {
>   return a - b;
> }
>
> // main.mjs
> import { add, subtract } from "./math.mjs";
> console.log(subtract(10, 3));   // 7
> ```

### 9.2 라이브러리와 프레임워크

입문서는 자동차 만들기로 비유합니다 (p.429). 지금까지는 **부품을 하나하나 직접 만든** 것입니다. **라이브러리**는 완성된 의자 같은 **기성 부품**이고, **프레임워크**는 이미 굴러가는 **차체 뼈대**에 내 취향만 더하는 것입니다. [[React]], [[React Native]], [[Expo]]가 바로 이런 라이브러리·프레임워크입니다.

### 9.4 가장 좋은 공부법
