# JS 첫걸음 01 - 프로그램과 콘솔

> **이전**: [[JS 첫걸음 00 - 로드맵|로드맵]] · **다음**: [[JS 첫걸음 02 - 변수|02 변수]]

## 이 레슨에서 배우는 것

1. 프로그램과 JavaScript가 무엇인지
2. 브라우저 **콘솔**을 열고 첫 코드를 실행하는 법
3. 코드를 읽기 좋게 쓰는 세 가지 습관: 들여쓰기, 세미콜론, 주석

## 1. 프로그램이란?

### 비유로 이해하기: 요리 레시피

라면 봉지 뒤에는 이런 순서가 적혀 있습니다.

1. 물 550ml를 끓인다.
2. 면과 스프를 넣는다.
3. 4분 30초 더 끓인다.

이 순서를 그대로 따라 하면 누가 끓여도 같은 라면이 나옵니다.

**프로그램**은 이 레시피와 같습니다. 컴퓨터에게 "이것을 하고, 그다음 저것을 해"라고 **순서대로 적어 준 지시문**입니다. 다만 컴퓨터는 사람처럼 눈치가 없어서, 정해진 규칙(문법)대로 정확하게 적어야만 알아듣습니다. 이렇게 컴퓨터가 알아듣는 규칙으로 쓴 글을 **코드(code)** 라고 하고, 그 규칙의 묶음을 **프로그래밍 언어**라고 합니다.

### JavaScript는 어떤 언어인가요?

- **JavaScript**(줄여서 JS)는 프로그래밍 언어 중 하나입니다. 1995년에 처음 만들어졌습니다 (입문서 p.27).
- 웹 사이트에서 버튼을 눌렀을 때 창이 뜨거나 메뉴가 펼쳐지는 것처럼, **웹 페이지가 움직이고 반응하는 부분**은 대부분 JavaScript로 만듭니다 (입문서 p.26).
- 웹 브라우저 안에서만 쓰는 언어는 아닙니다. 서버(인터넷 너머에서 데이터를 처리하는 컴퓨터)에서도 쓰고 (입문서 p.26), 이 위키의 목표인 스마트폰 앱([[React Native]])도 JavaScript로 만듭니다.

> 📖 MDN의 정의: "JavaScript is a cross-platform, object-oriented scripting language used to make webpages interactive" (MDN, *JavaScript Guide – Introduction*)

### 웹 페이지를 만드는 세 언어

입문서는 웹 페이지가 세 언어로 만들어진다고 설명합니다 (p.30).

| 언어 | 하는 일 | 집에 비유하면 (판단) |
|---|---|---|
| **HTML** | 페이지에 **무엇이** 있는지 (글, 제목, 그림) | 기둥과 벽 |
| **CSS** | 어떻게 **보이는지** (글자 색, 크기, 위치) | 벽지와 페인트 |
| **JavaScript** | 무엇을 **할 수 있는지** (클릭하면 반응하기) | 전기와 스위치 |

이 시리즈에서는 JavaScript만 배웁니다.

## 2. 컴퓨터는 JavaScript를 어떻게 알아들을까?

컴퓨터 안에는 JavaScript 코드를 읽고 실행해 주는 프로그램이 있습니다. 이것을 **JavaScript 엔진**이라고 부릅니다. 웹 브라우저(Chrome, Safari 등)에는 엔진이 이미 들어 있습니다. 그래서 **브라우저만 있으면 아무것도 설치하지 않고 JavaScript를 바로 실행**할 수 있습니다 (입문서 p.27).

> [!note] 조금 더 알기: "통역사"와 "번역가"
> 입문서는 JavaScript를 **통역하듯 실행하는 언어**(interpreted language)라고 설명합니다. 실행하기 전에 미리 통째로 번역(compile)해 두지 않고, 읽으면서 바로 실행한다는 뜻입니다 (p.29).
> 지금의 엔진은 그보다 똑똑합니다. MDN은 JavaScript를 "lightweight interpreted (or just-in-time compiled)" 언어라고 소개합니다. **자주 실행되는 부분은 실행 도중에 미리 번역해 두어 더 빠르게 돌린다**는 뜻입니다.
> 처음 배울 때는 "엔진이 코드를 읽고 실행해 준다" 정도만 알면 충분합니다.

### ECMAScript라는 말

공부하다 보면 **ECMAScript**(줄여서 ES)라는 말을 자주 봅니다. JavaScript가 어떻게 동작해야 하는지 정해 둔 **공식 규칙집**의 이름입니다 (입문서 p.30). 모든 브라우저가 같은 규칙집을 따르기 때문에, 같은 코드가 어느 브라우저에서나 똑같이 동작합니다.

## 3. 직접 해 보기: 브라우저 콘솔

**콘솔(console)** 은 JavaScript를 한 줄씩 입력하고 바로 결과를 볼 수 있는 창입니다. 브라우저 안에 들어 있습니다. 코드에 무슨 일이 일어나는지 확인하고 문제를 찾을 때 개발자들이 가장 많이 쓰는 도구입니다 (입문서 p.31).

### 3.1 콘솔 열기 (Chrome 기준)

| 컴퓨터 | 단축키 |
|---|---|
| Mac | `Command` + `Option` + `J` |
| Windows | `Ctrl` + `Shift` + `J` |

(출처: Chrome DevTools 공식 문서 *Run JavaScript in the Console*)

화면 아래나 옆에 창이 열리고, `>` 표시 옆에서 커서가 깜박입니다. 여기에 코드를 입력합니다. 빨간색이나 노란색 메시지가 이미 보여도 괜찮습니다. 지금 열린 웹 사이트가 남긴 메시지입니다 (입문서 p.31).

> [!tip] 깨끗한 연습장 만들기
> 주소창에 `about:blank`를 입력해 빈 페이지를 연 다음 콘솔을 열면, 다른 메시지 없이 연습할 수 있습니다.

### 3.2 첫 번째 계산

콘솔에 아래를 입력하고 `Enter`를 누릅니다.

```js
4 + 10
```

`14`가 나옵니다. 콘솔은 입력한 식을 계산해서 결과를 바로 보여 줍니다 (입문서 p.32, 연습문제 1.1). 몇 가지 더 해 봅니다.

```js
7 * 6     // 곱하기는 *  → 42
10 / 4    // 나누기는 /  → 2.5
```

### 3.3 화면에 글자 보여 주기: `console.log()`

```js
console.log("안녕하세요!");
```

결과:

```
안녕하세요!
```

`console.log( )`는 **괄호 안에 넣은 것을 콘솔에 보여 달라**는 명령입니다 (입문서 p.31). 앞으로 거의 모든 레슨에서 이 명령으로 결과를 확인합니다.

- 글자는 반드시 **따옴표(`"` 또는 `'`)로 감쌉니다.** 따옴표로 감싼 글자 덩어리를 **문자열(string)** 이라고 부릅니다. 레슨 03에서 자세히 배웁니다 (입문서 p.32).
- 따옴표가 있고 없고에 따라 결과가 달라집니다.

```js
console.log(4 + 10);     // 14       ← 계산한 결과
console.log("4 + 10");   // 4 + 10   ← 따옴표 안은 그냥 글자
```

### 3.4 여러 줄 입력하기

콘솔에서 `Enter`를 누르면 그 줄이 바로 실행됩니다. 여러 줄을 한꺼번에 쓰고 싶으면 **`Shift` + `Enter`** 로 줄을 바꿉니다 (MDN, *JavaScript Guide – Introduction*).

### 3.5 재미 삼아: 무작위 숫자

```js
console.log(Math.floor(Math.random() * 100));
```

실행할 때마다 0부터 99 사이의 숫자가 하나씩 나옵니다. 어떻게 동작하는지는 지금 몰라도 됩니다. 입문서도 "일단 이렇게 하면 무작위 숫자가 나온다는 것만 믿으라"고 합니다 (p.39–40). 퀴즈나 게임 예제에서 가끔 씁니다.

## 4. 코드를 읽기 좋게 쓰는 습관 세 가지

코드는 컴퓨터만 읽는 것이 아닙니다. 며칠 뒤의 나도 읽고, 다른 사람도 읽습니다.

### 4.1 들여쓰기

`{ }`(중괄호) 안에 들어가는 줄은 **한 칸 안으로 들여 씁니다.** 어디서 시작해서 어디서 끝나는지 한눈에 보입니다 (입문서 p.36–37). 아래 코드의 뜻은 아직 몰라도 됩니다. 모양만 비교해 보세요.

```js
// 들여쓰기 없음: 어디서 끝나는지 괄호를 세어야 함
if (status === "new") {
console.log("처음 오셨네요!");
}

// 들여쓰기 있음: 한눈에 보임
if (status === "new") {
  console.log("처음 오셨네요!");
}
```

### 4.2 세미콜론 `;`

문장 하나가 끝날 때마다 마침표처럼 **세미콜론 `;`** 을 붙입니다 (입문서 p.37).

- JavaScript는 한 줄에 하나씩 쓴 문장이라면 세미콜론을 빠뜨려도 대개 알아서 처리합니다. 그래도 **항상 붙이는 습관**을 들이라는 것이 입문서와 MDN의 공통된 권고입니다. MDN: "It is considered best practice, however, to always write a semicolon after a statement, even when it is not strictly needed." (*Grammar and types*)

### 4.3 주석 (메모)

**주석**은 코드 안에 남기는 메모입니다. 엔진은 주석을 **읽지 않고 건너뜁니다** (입문서 p.38).

```js
// 한 줄 주석: // 뒤로 그 줄 끝까지가 메모
console.log("나는 실행돼요"); // 줄 끝에도 쓸 수 있어요

/* 여러 줄 주석:
   이 사이에 있는 것은
   전부 실행되지 않아요
console.log("나도 실행되지 않아요");
*/
```

결과:

```
나는 실행돼요
```

주석은 이럴 때 씁니다 (입문서 p.38).
- 코드가 **왜** 이렇게 되어 있는지 설명을 남길 때
- 코드를 지우지 않고 **잠깐 실행을 멈추고** 싶을 때 (줄 앞에 `//`를 붙이는 것을 "주석 처리한다"고 합니다)

## 5. 정리

| 낱말 | 뜻 |
|---|---|
| 프로그램 | 컴퓨터에게 주는, 순서대로 적은 지시문 |
| 코드 | 프로그래밍 언어로 쓴 글 |
| JavaScript 엔진 | JavaScript 코드를 읽고 실행해 주는 프로그램. 브라우저에 들어 있음 |
| ECMAScript | JavaScript의 공식 규칙집 |
| 콘솔 | 코드를 입력하고 결과를 바로 보는 창 |
| `console.log()` | 괄호 안의 것을 콘솔에 보여 주는 명령 |
| 문자열 | 따옴표로 감싼 글자 덩어리 |
| 주석 | 엔진이 건너뛰는 메모 (`//`, `/* */`) |

## 6. 자주 하는 실수

에러 메시지는 Chrome과 Node.js 기준입니다. 다른 브라우저는 문구가 조금 다를 수 있습니다. 앞에 `Uncaught`가 붙어서 나오기도 합니다.

| 잘못 쓴 코드 | 나오는 에러 | 무엇이 문제인가 |
|---|---|---|
| `console.log(안녕하세요);` | `ReferenceError: 안녕하세요 is not defined` | 따옴표가 없으면 엔진은 이것을 글자가 아니라 **이름**으로 생각합니다. 그런 이름은 없다는 뜻입니다. |
| `Console.log("안녕!");` | `ReferenceError: Console is not defined` | JavaScript는 **대문자와 소문자를 다르게 봅니다** (MDN: "JavaScript is case-sensitive"). `console`은 소문자입니다. |
| `console.log("안녕!";` | `SyntaxError: missing ) after argument list` | 여는 괄호 `(`를 닫는 괄호 `)`로 닫지 않았습니다. |
| `console.log("안녕!);` | `SyntaxError: Invalid or unexpected token` | 여는 따옴표만 있고 닫는 따옴표가 없습니다. |

> [!tip] 에러 메시지 읽는 법
> 에러 메시지는 **"무슨 종류의 문제인지: 자세한 설명"** 모양입니다.
> - `SyntaxError`: **문법**이 틀렸다는 뜻입니다. 괄호, 따옴표 짝이 맞는지 봅니다.
> - `ReferenceError`: 그런 **이름을 찾을 수 없다**는 뜻입니다. 오타나 따옴표 빠뜨림을 봅니다.

## 7. 확인 퀴즈

**Q1.** 아래 두 줄은 각각 무엇을 보여 줄까요?
```js
console.log(3 + 5);
console.log("3 + 5");
```

> [!question]- 정답 보기
> 첫 줄은 `8`, 둘째 줄은 `3 + 5`입니다. 따옴표 안은 계산하지 않고 글자 그대로 보여 줍니다.

**Q2.** 콘솔에서 여러 줄을 한 번에 입력하려면 줄을 바꿀 때 어떤 키를 누를까요?

> [!question]- 정답 보기
> `Shift` + `Enter`입니다. 그냥 `Enter`를 누르면 그 줄이 바로 실행됩니다.

**Q3.** 코드 한 줄을 지우지 않고 잠깐 실행되지 않게 하려면 어떻게 할까요? (입문서 p.41, 퀴즈 4)

> [!question]- 정답 보기
> 그 줄 맨 앞에 `//`를 붙여 **주석 처리**합니다. 다시 실행하고 싶으면 `//`만 지우면 됩니다.

**Q4.** `console.Log("hi");`를 실행하면 에러가 납니다. 왜일까요?

> [!question]- 정답 보기
> `Log`의 `L`이 대문자이기 때문입니다. JavaScript는 대소문자를 구별하므로 `log`와 `Log`를 다른 이름으로 봅니다. 콘솔에는 `log`만 있습니다.

**Q5. (직접 해 보기)** 콘솔에 자기 이름을 출력하고, 그 줄 끝에 "내 이름을 출력한다"는 주석을 달아 보세요.

> [!question]- 예시 답안
> ```js
> console.log("김코딩"); // 내 이름을 출력한다
> ```
