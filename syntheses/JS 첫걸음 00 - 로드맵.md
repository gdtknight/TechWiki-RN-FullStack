# JS 첫걸음 00 - 로드맵

> 프로그래밍을 처음 배우는 사람을 위한 JavaScript 기초 레슨 시리즈의 안내 페이지입니다.
> 한 레슨에 한 가지 주제만 다룹니다. 모든 레슨은 같은 순서로 구성됩니다: **비유로 이해하기 → 직접 해 보기 → 정리 → 자주 하는 실수 → 확인 퀴즈**.

---

## 질문 / 문제 의식

- 위키에 있는 JavaScript 페이지([[JavaScript Core Syntax and Modern ES6+ Fundamentals]], [[JavaScript Execution Context, Closures, and Prototype]], [[JavaScript Event Loop and Asynchronous Patterns]])는 기초를 아는 사람을 위해 쓰였습니다. "TDZ", "렉시컬 스코프" 같은 말이 설명 없이 나옵니다.
- 이 시리즈는 그보다 앞 단계입니다. **처음 보는 낱말은 모두 그 자리에서 풀어서 설명**하고, 다 마치면 위의 페이지들을 읽을 수 있게 되는 것이 목표입니다.

---

## 공부하는 방법

1. **레슨을 순서대로 읽습니다.** 뒤 레슨은 앞 레슨에서 배운 낱말을 그대로 씁니다.
2. **코드는 꼭 직접 입력해 봅니다.** 눈으로 읽기만 하면 이해한 것 같아도 막상 쓰면 막힙니다. 레슨 01에서 브라우저 콘솔을 여는 법을 배웁니다.
3. **"자주 하는 실수"의 에러를 일부러 내 봅니다.** 에러 메시지를 한 번 본 적이 있으면 나중에 실제로 만났을 때 당황하지 않습니다.
4. **퀴즈는 정답을 접어 두었습니다.** 먼저 스스로 답해 보고 나서 펼쳐 봅니다.

> [!info] 쪽 번호 읽는 법
> 출처의 `p.XX`는 원천 PDF 파일의 쪽 번호입니다. 종이책에 인쇄된 쪽 번호와 다릅니다. 예를 들어 [[2021-JavaScript from Beginner to Professional]]의 PDF p.26은 인쇄본 1쪽입니다.
