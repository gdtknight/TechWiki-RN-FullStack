# JS 첫걸음 04 - 연산자

> **이전**: [[JS 첫걸음 03 - 자료형|03 자료형]] · **다음**: [[JS 첫걸음 05 - 조건문|05 조건문]] · **목록**: [[JS 첫걸음 00 - 로드맵|로드맵]]

## 이 레슨에서 배우는 것

1. **산술 연산자**: 더하기, 빼기, 곱하기, 나누기, 거듭제곱, 나머지
2. 계산 **순서**(우선순위)와 괄호
3. 값을 줄여 쓰는 **대입 연산자** (`+=`, `++`)
4. **비교 연산자**: 같은지, 큰지 작은지 (`===`, `>`)
5. **논리 연산자**: 그리고, 또는, 아니다 (`&&`, `||`, `!`)

---

## 1. 연산자란?

### 비유로 이해하기: 계산기 버튼

계산기에는 숫자 버튼과 `+`, `−`, `×`, `÷` 같은 기능 버튼이 있습니다. `3`, `+`, `4`를 누르면 `7`이 나오죠.

JavaScript에서 `+`, `-`, `*`, `/` 같은 기능 버튼을 **연산자**(operator)라고 합니다. 연산자가 일을 하는 대상(`3`과 `4`)은 **피연산자**(operand)라고 부릅니다 (입문서 p.61: "So, if we say x + y, x and y are operands.").

입문서는 연산자가 변수를 **바꾸고, 계산하고, 비교할 때** 쓰인다고 설명합니다 (p.57). 이 레슨에서는 그 세 가지를 차례로 배웁니다.

---

## 2. 산술 연산자: 계산하기

### 2.1 기본 다섯 가지

| 연산자 | 뜻 | 예 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `12 + 14` | `26` |
| `-` | 빼기 | `20 - 4` | `16` |
| `*` | 곱하기 | `15 * 10` | `150` |
| `/` | 나누기 | `30 / 5` | `6` |
| `**` | 거듭제곱 | `2 ** 3` | `8` (2 × 2 × 2) |

(입문서 p.57–60)

- 곱하기는 `×`가 아니라 **별표 `*`**, 나누기는 `÷`가 아니라 **빗금 `/`** 입니다.
- `**`는 "몇 번 곱하는가"입니다. `2 ** 3`은 2를 3번 곱한 것입니다 (입문서 p.59).

### 2.2 나머지 연산자 `%`

`%`는 퍼센트가 아니라 **나누고 남은 나머지**를 구합니다 (입문서 p.60). MDN: "The remainder (`%`) operator returns the remainder left over when one operand is divided by a second operand."

### 비유로 이해하기: 사탕 나누기

사탕 10개를 3명에게 똑같이 나눠 주면, 한 명당 3개씩 주고 **1개가 남습니다**. 그래서 `10 % 3`은 `1`입니다.

```js
console.log(10 % 3);   // 1  (3명에게 3개씩, 1개 남음)
console.log(8 % 2);    // 0  (딱 나누어떨어짐)
console.log(15 % 4);   // 3  (4명에게 3개씩, 3개 남음)
```

나머지 연산자는 생각보다 자주 씁니다.

- **짝수/홀수 구별**: 2로 나눈 나머지가 `0`이면 짝수, `1`이면 홀수입니다.

  ```js
  console.log(6 % 2);   // 0 → 짝수
  console.log(7 % 2);   // 1 → 홀수
  ```

- **분을 시간과 분으로 나누기**: 입문서는 "125분 뒤"를 계산하는 예를 듭니다 (p.61). 125분은 2시간 5분입니다. 5분이 바로 `125 % 60`입니다.

  ```js
  console.log(Math.floor(125 / 60));   // 2  ← 몇 시간 (Math.floor는 내림: 2.08… → 2)
  console.log(125 % 60);               // 5  ← 남은 분
  ```

### 2.3 문자열과 계산하면?

[[JS 첫걸음 03 - 자료형|레슨 03]]에서 `+`는 문자열을 이어 붙인다고 배웠습니다. 다른 연산자는 어떨까요?

```js
console.log("Hi" - 3);   // NaN
console.log("Hi" * 3);   // NaN
console.log("10" - 3);   // 7
console.log("10" + 3);   // 103
```

- `"Hi"`는 숫자로 바꿀 수 없으니 빼기·곱하기 결과가 `NaN`입니다. 에러가 나지 않고 "숫자가 아님"이라고 답합니다 (입문서 p.58–59).
- `"10" - 3`은 `"10"`을 숫자 10으로 몰래 바꿔서 `7`이 됩니다.
- `"10" + 3`은 반대로 3을 글자로 바꿔 이어 붙여서 `"103"`이 됩니다.

**`+`만 문자열을 이어 붙이는 기능이 있어서** 결과가 다릅니다. 숫자 계산을 할 때는 미리 `Number()`로 바꿔 두는 것이 안전합니다 (레슨 03의 6.2절).

## 3. 계산 순서: 우선순위와 괄호

### 3.1 수학 시간과 같습니다

수학에서 곱셈을 덧셈보다 먼저 하듯, JavaScript도 연산자마다 **먼저 계산하는 순서**가 정해져 있습니다. 이것을 **연산자 우선순위**(operator precedence)라고 합니다 (입문서 p.62).

```js
console.log(2 + 3 * 4);     // 14  (곱셈 먼저: 3 * 4 = 12, 그다음 2 + 12)
console.log((2 + 3) * 4);   // 20  (괄호 먼저: 2 + 3 = 5, 그다음 5 * 4)
```

이 레슨에서 배우는 산술 연산자의 순서 (위에 있을수록 먼저):

| 순서 | 연산자 |
|---|---|
| 1 | `( )` 괄호 |
| 2 | `**` 거듭제곱 |
| 3 | `*`, `/`, `%` |
| 4 | `+`, `-` |

(MDN *Operator precedence* 표 기준. 괄호 18, 거듭제곱 13, 곱셈류 12, 덧셈류 11)

- **순서가 같으면 왼쪽부터** 계산합니다 (입문서 p.63). `10 - 4 - 3`은 `(10 - 4) - 3` = `3`입니다.
- 예외로 `**`만 **오른쪽부터** 계산합니다. MDN: "the unique exponentiation operator has right-associativity". `2 ** 3 ** 2`는 `2 ** 9` = `512`입니다.

> [!tip] 헷갈리면 괄호
> 순서를 외우기 어렵다면 **먼저 하고 싶은 부분을 괄호로 감싸세요**. 괄호는 항상 가장 먼저 계산되고, 나중에 읽는 사람도 순서를 바로 알 수 있습니다 (판단).

## 4. 대입 연산자: 줄여 쓰기

### 4.1 `+=`, `-=`, `*=`, `/=`

[[JS 첫걸음 02 - 변수|레슨 02]]에서 `score = score + 5`처럼 쓰는 법을 배웠습니다. 이것을 짧게 줄여 쓸 수 있습니다 (입문서 p.63: "x += 5 means x = x + 5").

| 줄여 쓴 것 | 원래 뜻 |
|---|---|
| `x += 2` | `x = x + 2` |
| `x -= 2` | `x = x - 2` |
| `x *= 6` | `x = x * 6` |
| `x /= 3` | `x = x / 3` |
| `x **= 2` | `x = x ** 2` |
| `x %= 3` | `x = x % 3` |

입문서의 예를 따라가 봅니다 (p.64).

```js
let x = 2;
x += 2;    console.log(x);   // 4
x -= 2;    console.log(x);   // 2
x *= 6;    console.log(x);   // 12
x /= 3;    console.log(x);   // 4
x **= 2;   console.log(x);   // 16
x %= 3;    console.log(x);   // 1
```

`+=`는 문자열에도 씁니다.

```js
let msg = "안녕";
msg += "하세요";
console.log(msg);   // 안녕하세요
```

### 4.2 1 올리기, 1 내리기: `++`, `--`

1을 더하거나 빼는 일은 아주 흔해서 더 짧은 방법이 있습니다 (입문서 p.61).

| 쓰는 법 | 뜻 |
|---|---|
| `x++` | `x`를 1 올린다 (`x = x + 1`) |
| `x--` | `x`를 1 내린다 (`x = x - 1`) |

```js
let score = 0;
score++;
score++;
score++;
console.log(score);   // 3
```

### `++`를 앞에 쓸 때와 뒤에 쓸 때

`++x`(앞)와 `x++`(뒤)는 둘 다 `x`를 1 올리지만, **그 자리에 남기는 값**이 다릅니다. MDN:
- `x++`: "increments and returns the value before incrementing" → 올리기 **전** 값을 남김
- `++x`: "increments and returns the value after incrementing" → 올린 **후** 값을 남김

```js
let n = 2;
console.log(n++);   // 2  ← 올리기 전 값이 출력됨
console.log(n);     // 3  ← 하지만 n은 이미 3

let m = 2;
console.log(++m);   // 3  ← 올린 후 값이 출력됨
```

입문서도 이 부분이 어려우니 여러 번 읽어도 괜찮다고 합니다 (p.61).

> [!tip] 이렇게 쓰면 헷갈릴 일이 없어요
> `++`와 `--`는 **한 줄에 혼자** 쓰세요 (`score++;`). 혼자 쓰면 앞에 붙이든 뒤에 붙이든 결과가 같습니다. `console.log(n++)`나 `a++ + ++b`처럼 다른 계산 속에 섞으면 읽는 사람이 헷갈립니다 (판단).

## 5. 비교 연산자: 비교하기

비교 연산자의 결과는 **항상 불리언**(`true` 또는 `false`)입니다 (입문서 p.65: "The outcome of the comparison operators is always a Boolean, true, or false.").

### 5.1 크기 비교

| 연산자 | 뜻 | 예 (x = 5, y = 6) | 결과 |
|---|---|---|---|
| `>` | 크다 | `y > x` | `true` |
| `<` | 작다 | `y < x` | `false` |
| `>=` | 크거나 같다 | `y >= y` | `true` |
| `<=` | 작거나 같다 | `y <= y` | `true` |

(입문서 p.66–67)

`>=`는 "**>** 또는 **=**"입니다. 순서를 바꿔 `=>`로 쓰면 안 됩니다. `=>`는 레슨 07에서 배울 전혀 다른 기호입니다.

### 5.2 같은지 비교: `===`를 쓰세요

같은지 비교하는 연산자는 두 종류입니다 (입문서 p.65).

| 연산자 | 이름 | 무엇을 비교하나 |
|---|---|---|
| `==` | 느슨한 같음 (loose equality) | **값만** 비교. 자료형이 다르면 몰래 바꾼 뒤 비교 |
| `===` | 엄격한 같음 (strict equality) | **값과 자료형 둘 다** 비교 |

```js
console.log(5 == "5");    // true   ← "5"를 숫자로 바꿔서 비교
console.log(5 === "5");   // false  ← 숫자와 문자열은 종류가 달라서 다름
```

MDN: "Unlike the equality operator, the strict equality operator always considers operands of different types to be different."

`==`는 몰래 자료형을 바꾸기 때문에 이런 이상한 결과가 나옵니다.

```js
console.log(0 == "");      // true  ← 숫자 0과 빈 문자열이 같다고?
console.log(0 == false);   // true
console.log(0 === "");     // false ← 이게 상식적
```

입문서도 `===`를 가장 자주 써야 한다고 합니다. "only with this one can you be sure that both variables are really equal" (p.65). **이 시리즈에서는 항상 `===`를 씁니다.**

### 5.3 다른지 비교: `!==`

`!`는 "아니다"라는 뜻입니다. 그래서 `!==`는 "엄격하게 같지 **않다**"입니다 (입문서 p.65–66).

```js
console.log(5 !== "5");   // true  ← 자료형이 달라서 같지 않다
console.log(5 != "5");    // false ← 느슨한 비교로는 같다고 봄
```

같음과 마찬가지로 **`!=` 대신 `!==`** 를 씁니다.

### 5.4 레슨 03에서 미뤄 둔 이야기

- **`null` 확인**: `typeof null`은 `"object"`가 나오는 버그가 있어서, `null`인지는 `=== null`로 확인합니다 (레슨 03의 5절).

  ```js
  let pet = null;
  console.log(pet === null);   // true
  ```

- **`NaN`은 자기 자신과도 같지 않습니다.** MDN: "`NaN` is the only value that compares unequal to itself". 그래서 `NaN`인지 확인할 때는 `===`가 아니라 `Number.isNaN()`을 씁니다 (레슨 03의 3.3절).

  ```js
  console.log(NaN === NaN);   // false
  ```

## 6. 논리 연산자: 조건 합치기

조건 두 개를 하나로 합치거나, 조건을 반대로 뒤집을 때 씁니다 (입문서 p.67).

### 6.1 `&&` (그리고, AND)

**양쪽이 모두 `true`일 때만** `true`입니다 (입문서 p.67).

### 비유로 이해하기: 놀이기구 탑승 조건

"키가 120cm 이상 **그리고** 보호자와 함께"인 놀이기구라면, 두 조건을 **모두** 만족해야 탈 수 있습니다. 하나라도 안 되면 못 탑니다.

| 왼쪽 | 오른쪽 | `왼쪽 && 오른쪽` |
|---|---|---|
| `true` | `true` | `true` |
| `true` | `false` | `false` |
| `false` | `true` | `false` |
| `false` | `false` | `false` |

```js
const age = 12;
console.log(age >= 8 && age <= 13);   // true  ← 8살 이상 그리고 13살 이하
```

> [!warning] 수학식처럼 이어 쓰면 안 돼요
> "8 ≤ age ≤ 13"을 `8 <= age <= 13`처럼 쓰면 원하는 대로 동작하지 않습니다. 반드시 `age >= 8 && age <= 13`처럼 **두 비교를 `&&`로 이어** 씁니다.

### 6.2 `||` (또는, OR)

**한쪽이라도 `true`이면** `true`입니다 (입문서 p.68). 세로 막대 `|`를 두 번 붙여 씁니다.

### 비유로 이해하기: 학교 쉬는 날

"주말 **또는** 공휴일"이면 학교에 가지 않습니다. 둘 중 하나만 맞아도 쉽니다.

| 왼쪽 | 오른쪽 | `왼쪽 \|\| 오른쪽` |
|---|---|---|
| `true` | `true` | `true` |
| `true` | `false` | `true` |
| `false` | `true` | `true` |
| `false` | `false` | `false` |

```js
const isWeekend = false;
const isHoliday = true;
console.log(isWeekend || isHoliday);   // true  ← 공휴일이니까 쉰다
```

### 6.3 `!` (아니다, NOT)

`true`를 `false`로, `false`를 `true`로 **뒤집습니다** (입문서 p.68).

```js
console.log(!true);    // false
console.log(!false);   // true
```

계산식 전체를 뒤집으려면 괄호로 감쌉니다 (입문서 p.68).

```js
console.log(!(1 < 2));   // false  ← 1 < 2는 true, 뒤집어서 false
```

> [!note] 조금 더 알기: `&&`와 `||`가 실제로 돌려주는 값
> 입문서는 `&&`와 `||`의 결과를 `true`/`false`로만 설명합니다. 실제로는 **양쪽 값 중 하나를 그대로** 돌려줍니다. MDN: "the `||` operator actually returns the value of one of the specified operands, so if this operator is used with non-Boolean values, it will return a non-Boolean value."
> ```js
> console.log("" || "기본값");     // 기본값
> console.log("철수" || "기본값");  // 철수
> console.log(0 && "배");          // 0
> ```
> 양쪽이 불리언이면 결과도 불리언이라 차이가 없습니다. 이 동작은 나중에 React 화면을 만들 때 중요해집니다 ([[JavaScript Core Syntax and Modern ES6+ Fundamentals]] 2.2절). 지금은 "**불리언끼리 쓰면 결과도 불리언**"만 기억하면 됩니다.

## 7. 정리

| 낱말 | 뜻 |
|---|---|
| 연산자 / 피연산자 | 계산 기호 / 계산 대상 |
| `%` | 나눗셈의 나머지. 짝수·홀수 구별에 씀 |
| `**` | 거듭제곱 |
| 연산자 우선순위 | 먼저 계산하는 순서. `()` → `**` → `* / %` → `+ -` |
| `+=`, `-=` 등 | `x = x + …`를 줄여 쓴 것 |
| `++`, `--` | 1 올리기, 1 내리기. 한 줄에 혼자 쓰기 |
| `===`, `!==` | 값과 자료형을 모두 비교. 항상 이것을 씀 |
| `==`, `!=` | 자료형을 몰래 바꾼 뒤 비교. 쓰지 않음 |
| `&&` | 그리고. 둘 다 `true`여야 `true` |
| `\|\|` | 또는. 하나라도 `true`면 `true` |
| `!` | 아니다. `true`↔`false` 뒤집기 |

## 8. 자주 하는 실수

| 잘못 쓴 코드 | 결과 | 무엇이 문제인가 |
|---|---|---|
| `if (x = 5)`처럼 비교 자리에 `=` 하나 | 비교가 아니라 **대입**이 됨 | 같은지 비교는 `===`입니다. `=`는 넣기, `===`는 비교. (`if`는 레슨 05) |
| `5 == "5"`가 `true`라서 같은 값이라고 생각 | `true` | `==`는 자료형을 몰래 바꿉니다. `5 === "5"`는 `false`입니다. |
| `8 <= age <= 13` (`age`가 20일 때) | `true` | 왼쪽부터 `8 <= 20`을 계산해 `true`가 되고, 그다음 `true <= 13`을 계산하면서 `true`를 숫자 1로 바꿔 `1 <= 13` → `true`가 됩니다 (MDN *Less than*: "Boolean values `true` and `false` are converted to 1 and 0 respectively."). `age >= 8 && age <= 13`으로 나눠 씁니다. |
| `x => 3` (크거나 같다를 쓰려고) | 전혀 다른 문법이 됨 | 크거나 같다는 `>=`입니다. 등호가 뒤에 옵니다. |
| `"10" + 5`가 15일 거라고 생각 | `105` | 문자열이 있으면 `+`는 이어 붙입니다. `Number("10") + 5`. |
| `10 % 3`을 퍼센트로 생각 | `1` | `%`는 나머지입니다. |
| `NaN === NaN`으로 `NaN` 확인 | `false` | `Number.isNaN()`을 씁니다. |

## 9. 확인 퀴즈

**Q1.** 각 식의 결과는 무엇일까요?
① `17 % 5` ② `2 ** 4` ③ `3 + 4 * 2 / 8` (입문서 퀴즈 8, p.70)

> [!question]- 정답 보기
> ① `2` (5씩 3번 나누고 2가 남음) ② `16` (2를 4번 곱함) ③ `4` (곱셈·나눗셈 먼저: 4 × 2 = 8, 8 ÷ 8 = 1, 그다음 3 + 1)

**Q2.** 아래 코드가 끝나면 `points`에는 무엇이 들어 있을까요?
```js
let points = 10;
points += 5;
points *= 2;
```

> [!question]- 정답 보기
> `30`입니다. `10` → `15` → `30`.

**Q3.** 다음 두 줄은 각각 무엇을 출력할까요?
```js
console.log(7 === "7");
console.log(7 == "7");
```

> [!question]- 정답 보기
> `false`, `true`입니다. `===`는 자료형까지 보므로 숫자 7과 문자열 "7"은 다릅니다. `==`는 문자열을 숫자로 바꿔서 비교하므로 같다고 봅니다.

**Q4.** 기온이 20도보다 높고 30도보다 낮을 때 `true`가 되는 식을 쓰세요. 기온은 변수 `temp`에 들어 있습니다.

> [!question]- 정답 보기
> ```js
> temp > 20 && temp < 30
> ```
> `temp`가 25면 `true`, 35면 `false`입니다.

**Q5.** 숫자 `n`이 짝수인지 확인하는 식을 쓰세요.

> [!question]- 정답 보기
> ```js
> n % 2 === 0
> ```
> 2로 나눈 나머지가 0이면 짝수입니다. `n`이 7이면 `false`, 8이면 `true`입니다.

**Q6.** 135분은 몇 시간 몇 분일까요? `Math.floor`와 `%`를 써서 계산해 보세요.

> [!question]- 정답 보기
> ```js
> console.log(Math.floor(135 / 60));   // 2
> console.log(135 % 60);               // 15
> ```
> 2시간 15분입니다.

**Q7.** 다음 식의 결과는 `true`일까요, `false`일까요?
```js
console.log(!(5 > 3) || 10 === 10);
```

> [!question]- 정답 보기
> `true`입니다. `5 > 3`은 `true`이고, `!`로 뒤집어 `false`가 됩니다. `10 === 10`은 `true`입니다. `false || true`이므로 결과는 `true`입니다.

**Q8. (직접 해 보기)** 입문서 연습문제 2.2를 해 보세요 (p.58). 이름, 나이, JavaScript를 할 줄 아는지(`true`/`false`)를 변수에 넣고, 템플릿 리터럴로 한 문장을 만들어 출력합니다.

> [!question]- 예시 답안
> ```js
> const myName = "김코딩";
> const myAge = 12;
> const canCode = true;
> console.log(`안녕, 내 이름은 ${myName}이고 ${myAge}살이야. JavaScript를 할 줄 알아: ${canCode}`);
> // 안녕, 내 이름은 김코딩이고 12살이야. JavaScript를 할 줄 알아: true
> ```

| 항목 | 입문서 (2021) | MDN 기준 |

| 우선순위 표 | 거듭제곱(`**`)을 전위 증가·감소(`++x`, `--x`)보다 **위**에 둠 (p.63) | 전위 연산자(14)가 거듭제곱(13)보다 **먼저** 계산됨 (*Operator precedence*). 이 레슨의 표는 MDN 순서를 따름. |
