## 1. 배열이란?

### 비유로 이해하기: 번호 붙은 사물함 한 줄

[[JS 첫걸음 02 - 변수|레슨 02]]에서 변수는 값 **하나**를 담는 상자였습니다. 그런데 반 친구 30명의 이름을 저장하려면 변수를 30개 만들어야 할까요?

```js
let student1 = "철수";
let student2 = "영희";
let student3 = "민수";
// ... 30개?
```

**배열**(array)은 **번호가 붙은 사물함 한 줄**입니다. 사물함 줄 전체에 이름표를 하나 붙이고, 각 칸은 **번호**로 찾습니다.

```js
const students = ["철수", "영희", "민수"];
```

입문서는 배열을 장보기 목록에 비유합니다. 사과, 달걀, 빵을 담은 목록 하나가 변수 하나에 들어 있는 것입니다 (p.72: "This list would take the form of a single variable, holding multiple values.").

## 2. 배열 만들기와 꺼내기

### 2.1 만들기

**대괄호 `[ ]`** 안에 값을 **쉼표**로 나눠 씁니다 (입문서 p.73).

```js
const fruits = ["사과", "바나나", "포도"];
const scores = [90, 75, 88];
const empty = [];                  // 빈 배열
const mixed = ["안녕", 5, true];   // 여러 자료형을 섞어도 됨
```

MDN: "JavaScript arrays are resizable and can contain a mix of different data types." 다만 실제로는 **같은 종류끼리** 담는 경우가 대부분입니다 (판단).

> [!note] `typeof`로 보면?
> `typeof fruits`는 `"object"`입니다. 배열은 레슨 09에서 배울 **객체의 한 종류**이기 때문입니다 (입문서 p.72: "An array is a type of object"). 배열인지 확인하려면 `Array.isArray(fruits)`를 씁니다 (결과 `true`).

### 2.2 순서 번호로 꺼내기: 인덱스

배열의 각 칸에는 **0부터 시작하는** 번호가 붙습니다. 이 번호를 **인덱스**(index)라고 합니다. MDN: "JavaScript arrays are zero-indexed: the first element of an array is at index `0`, the second is at index `1`, and so on".

```
       ┌──────┬────────┬──────┐
fruits │ 사과 │ 바나나 │ 포도 │
       └──────┴────────┴──────┘
 인덱스    0       1       2
```

배열 이름 뒤에 **`[번호]`** 를 붙여 꺼냅니다 (입문서 p.75).

```js
console.log(fruits[0]);   // 사과
console.log(fruits[1]);   // 바나나
console.log(fruits[2]);   // 포도
console.log(fruits[3]);   // undefined  ← 없는 칸
```

> [!warning] 첫 번째는 1번이 아니라 0번!
> 처음에 가장 많이 헷갈리는 부분입니다. "첫 번째 = 0번, 두 번째 = 1번"입니다. 없는 번호를 꺼내면 에러가 아니라 `undefined`가 나옵니다 (입문서 p.75).

### 2.3 길이: `length`

`length`는 배열에 **몇 칸이 있는지** 알려 줍니다 (입문서 p.76).

```js
console.log(fruits.length);   // 3
console.log([].length);       // 0
```

인덱스는 0부터 시작하므로 **마지막 칸의 번호는 `length - 1`** 입니다 (입문서 p.77; MDN: "the last element is at the value of the array's `length` property minus `1`").

```js
console.log(fruits[fruits.length - 1]);   // 포도
console.log(fruits.at(-1));               // 포도
```

`at()`은 **음수**를 넣으면 뒤에서부터 셉니다. MDN: "Negative integers count back from the last item in the array." `at(-1)`은 마지막, `at(-2)`는 끝에서 두 번째입니다.

> `fruits[-1]`처럼 대괄호에 음수를 넣으면 `undefined`가 나옵니다. 뒤에서부터 세기는 `at()`만 됩니다.

### 2.4 값 바꾸기

꺼낼 때처럼 인덱스를 써서 **새 값을 대입**합니다 (입문서 p.75–76).

```js
fruits[1] = "딸기";
console.log(fruits);   // [ '사과', '딸기', '포도' ]
```

### 2.5 `const` 배열도 안의 값은 바꿀 수 있어요

`fruits`를 `const`로 만들었는데 값이 바뀌었습니다. [[JS 첫걸음 02 - 변수|레슨 02]]의 "미리 보기"에서 말한 경우입니다 (입문서 p.74).

```js
const bag = ["연필"];
bag[0] = "지우개";     // ✅ 칸 안의 물건 바꾸기
bag.push("자");        // ✅ 칸 추가하기
console.log(bag);      // [ '지우개', '자' ]

bag = ["새 가방"];     // ❌ TypeError: Assignment to constant variable.
```

`const`는 **사물함 줄 자체를 다른 줄로 바꿔 끼우는 것**만 막습니다. 줄 안의 칸에 무엇을 넣고 빼는지는 막지 않습니다 (MDN *const*: "It does not mean the value it holds is immutable — just that the variable identifier cannot be reassigned.").

## 3. 값 넣고 빼기

### 3.1 끝에서: `push`, `pop`

```js
const line = ["철수", "영희"];

line.push("민수");       // 끝에 넣기
console.log(line);       // [ '철수', '영희', '민수' ]

line.pop();              // 끝에서 빼기
console.log(line);       // [ '철수', '영희' ]
```

- `push`: MDN, "adds the specified elements to the end of an array and returns the new length of the array" (입문서 p.78)
- `pop`: 마지막 값을 빼고 (입문서 p.80), **뺀 값을 돌려줍니다** (Node.js 실행 결과: 위 코드에서 `line.pop()`은 `"민수"`를 돌려줌).

### 3.2 앞에서: `unshift`, `shift`

```js
line.unshift("지수");    // 앞에 넣기
console.log(line);       // [ '지수', '철수', '영희' ]

line.shift();            // 앞에서 빼기
console.log(line);       // [ '철수', '영희' ]
```

`shift`로 앞을 빼면 나머지 값들의 인덱스가 하나씩 앞당겨집니다 (입문서 p.81).

### 비유로 이해하기: 급식 줄

| 메서드 | 급식 줄에서 |
|---|---|
| `push` | 맨 뒤에 한 명 줄 서기 |
| `pop` | 맨 뒤 사람이 줄에서 나가기 |
| `unshift` | 맨 앞에 한 명 끼워 넣기 |
| `shift` | 맨 앞 사람이 배식 받고 나가기 |

### 3.3 중간에서: `splice`

중간에 넣거나 뺄 때는 `splice(시작 번호, 뺄 개수, 넣을 값…)`를 씁니다 (입문서 p.79–81).

```js
const shapes = ["원", "삼각형", "사각형", "오각형"];

shapes.splice(1, 1);          // 1번부터 1개 빼기
console.log(shapes);          // [ '원', '사각형', '오각형' ]

shapes.splice(1, 0, "별");    // 1번 자리에 0개 빼고 "별" 넣기
console.log(shapes);          // [ '원', '별', '사각형', '오각형' ]
```

### 3.4 칸 번호로 마구 넣지 마세요

`length`보다 큰 번호에 값을 넣으면 **중간에 빈칸이 생깁니다** (입문서 p.77).

```js
const nums = [12, 24, 36];
nums[5] = 48;
console.log(nums.length);   // 6
console.log(nums);          // [ 12, 24, 36, <2 empty items>, 48 ]
```

입문서는 이것이 "올바른 방법이 아니다"라고 하고, 끝에 넣을 때는 `push`를 쓰라고 합니다 (p.76, p.78).

## 4. 값 찾기

| 메서드 | 묻는 것 | 결과 |
|---|---|---|
| `includes(값)` | "이 값이 **들어 있니**?" | `true` / `false` |
| `indexOf(값)` | "이 값이 **몇 번**에 있니?" | 인덱스, 없으면 `-1` |
| `find(함수)` | "조건에 맞는 **첫 번째 값**은?" | 그 값, 없으면 `undefined` |

```js
const menu = ["짜장", "짬뽕", "탕수육"];

console.log(menu.includes("짬뽕"));     // true
console.log(menu.includes("볶음밥"));   // false
console.log(menu.indexOf("탕수육"));    // 2
console.log(menu.indexOf("볶음밥"));    // -1
```

- `includes`: MDN, "determines whether an array includes a certain value among its entries, returning `true` or `false` as appropriate."
- `indexOf`: 없으면 `-1`을 돌려줍니다 (입문서 p.82).

`find`는 [[JS 첫걸음 07 - 함수|레슨 07]]의 **콜백**을 받습니다. 배열의 값을 하나씩 콜백에 넣어 보고, 처음으로 `true`를 돌려준 값을 줍니다 (입문서 p.81–82). MDN: "returns the first element in the provided array that satisfies the provided testing function. If no values satisfy the testing function, `undefined` is returned."

```js
const nums = [5, 12, 8, 130];
console.log(nums.find(n => n > 10));   // 12  (130도 맞지만 첫 번째만)
console.log([5, 8].find(n => n > 10)); // undefined
```

## 5. 하나씩 훑기 (반복)

[[JS 첫걸음 06 - 반복문|레슨 06]]의 반복문과 배열은 단짝입니다 (입문서 p.123: "Loops make life with arrays a lot more comfortable.").

### 5.1 `for`: 인덱스가 필요할 때

조건에 `length`를 써서 0번부터 마지막 번까지 돕니다 (입문서 p.123).

```js
const scores = [90, 75, 88];
for (let i = 0; i < scores.length; i++) {
  console.log(`${i}번: ${scores[i]}점`);
}
```

결과:

```
0번: 90점
1번: 75점
2번: 88점
```

`i <= scores.length`라고 쓰면 마지막에 없는 칸(`scores[3]`, `undefined`)까지 꺼냅니다. **`<`** 를 씁니다.

### 5.2 `for...of`: 값만 필요할 때

인덱스 없이 **값만** 차례로 꺼냅니다 (입문서 p.126–127). MDN: "The `for...of` statement executes a loop that operates on a sequence of values sourced from an iterable object."

```js
for (const score of scores) {
  console.log(score);   // 90, 75, 88
}
```

"`scores`의 각 값을 `score`라고 부르고 다음을 해라"로 읽습니다 (입문서 p.127). 인덱스를 다룰 일이 없어 실수가 적습니다.

예: 평균 구하기

```js
let sum = 0;
for (const score of scores) {
  sum += score;
}
console.log(sum / scores.length);   // 84.33333333333333
```

### 5.3 `forEach`: 함수로 훑기

배열이 가진 메서드로, 각 값마다 **콜백을 한 번씩** 실행합니다 (입문서 p.201–202). MDN: "The `forEach()` method of `Array` instances executes a provided function once for each array element." 콜백의 두 번째 매개변수로 인덱스도 받을 수 있습니다.

```js
scores.forEach((score, i) => {
  console.log(i, score);
});
```

> [!note] `forEach`는 중간에 멈출 수 없어요
> MDN: "There is no way to stop or break a `forEach()` loop other than by throwing an exception." 중간에 멈춰야 하면 `for`나 `for...of`와 `break`를 씁니다 (레슨 06).

## 6. 배열로 새 배열 만들기: `map`과 `filter`

두 메서드는 **원래 배열은 그대로 두고 새 배열을 돌려줍니다** (입문서 p.203–204). 실무 코드에서 가장 많이 보는 메서드입니다 (판단).

### 6.1 `map`: 모든 값을 바꾼 새 배열

### 비유로 이해하기: 붕어빵 틀

반죽 하나하나를 틀에 넣으면 붕어빵이 하나씩 나옵니다. 반죽 3개 → 붕어빵 3개. `map`도 **값 하나마다 콜백을 적용한 결과**를 모아 **같은 개수의 새 배열**을 만듭니다 (판단). MDN: "creates a new array populated with the results of calling a provided function on every element in the calling array."

```js
const nums = [1, 2, 3, 4];
const doubled = nums.map(n => n * 2);
console.log(doubled);   // [ 2, 4, 6, 8 ]
console.log(nums);      // [ 1, 2, 3, 4 ]  ← 원래 배열은 그대로

const names = ["민수", "지수", "철수"];
console.log(names.map(name => `${name}님`));   // [ '민수님', '지수님', '철수님' ]
```

### 6.2 `filter`: 조건에 맞는 것만 고른 새 배열

### 비유로 이해하기: 체

체에 흙을 부으면 작은 알갱이만 빠져나옵니다. `filter`는 콜백이 **`true`를 돌려준 값만** 통과시킵니다 (입문서 p.202: "If the Boolean has the value true, the element will end up in the filtered array."). MDN: "creates a shallow copy of a portion of a given array, filtered down to just the elements from the given array that pass the test implemented by the provided function."

```js
const scores = [90, 45, 72, 58];
const passed = scores.filter(s => s >= 60);
console.log(passed);   // [ 90, 72 ]

const evens = [1, 2, 3, 4, 5, 6].filter(n => n % 2 === 0);
console.log(evens);    // [ 2, 4, 6 ]
```

### 6.3 한눈에 비교

| 메서드 | 콜백이 돌려줄 것 | 결과 | 개수 |
|---|---|---|---|
| `forEach` | (무엇이든, 쓰지 않음) | 항상 `undefined` | — |
| `map` | **바뀐 값** | 새 배열 | 원래와 같음 |
| `filter` | **`true` / `false`** | 새 배열 | 같거나 적음 |
| `find` | **`true` / `false`** | 값 하나 또는 `undefined` | — |

(`forEach`의 결과: MDN, "Unlike `map()`, `forEach()` always returns `undefined` and is not chainable.")

## 7. 정렬하기: `sort`의 함정

`sort()`는 배열을 **정렬하고 원래 배열 자체를 바꿉니다**. MDN: "sorts the elements of an array in place".

```js
const names = ["James", "Alicia", "Bert"];
names.sort();
console.log(names);   // [ 'Alicia', 'Bert', 'James' ]
```

글자는 잘 정렬됩니다. 그런데 **숫자**는 조심해야 합니다.

```js
const nums = [40, 1, 5, 200];
nums.sort();
console.log(nums);    // [ 1, 200, 40, 5 ]  ← ⚠️ 크기 순서가 아니에요!
```

MDN: "The default sort order is ascending, built upon converting the elements into strings, then comparing their sequences of UTF-16 code unit values." 즉 `sort()`는 숫자를 **글자로 바꿔서 사전 순서처럼** 비교합니다. 글자 `"200"`은 `"2"`로 시작하므로 `"40"`보다 앞에 옵니다.

숫자를 크기 순서로 정렬하려면 **비교 함수** `(a, b) => a - b`를 넣습니다. MDN: "remember that `(a, b) => a - b` sorts numbers in ascending order."

```js
nums.sort((a, b) => a - b);
console.log(nums);    // [ 1, 5, 40, 200 ]
```

큰 수부터 정렬하려면 `(a, b) => b - a`입니다. 비교 함수가 어떻게 동작하는지는 지금 몰라도 됩니다. **숫자 정렬에는 `(a, b) => a - b`** 라고 외워 두세요.

순서만 뒤집을 때는 `reverse()`를 씁니다 (입문서 p.83). `[1, 2, 3].reverse()`는 `[3, 2, 1]`입니다.

## 8. 펼치기: `...`

점 세 개 **`...`** 를 배열 앞에 붙이면, 배열의 **칸을 하나하나 펼쳐 놓습니다** (입문서 p.150). MDN: "The spread (`...`) syntax allows an iterable, such as an array or string, to be expanded in places where zero or more arguments (for function calls) or elements (for array literals) are expected."

### 8.1 배열 합치기

```js
const a = [1, 2, 3];
const b = [4, 5];
console.log([...a, ...b]);       // [ 1, 2, 3, 4, 5 ]
console.log([0, ...a, 99]);      // [ 0, 1, 2, 3, 99 ]
```

### 8.2 배열 복사하기

```js
const original = [1, 2, 3];

const same = original;      // 같은 사물함 줄을 가리킴
const copy = [...original]; // 새 사물함 줄을 만들어 내용을 옮김

copy.push(100);
console.log(original);   // [ 1, 2, 3 ]       ← copy를 바꿔도 그대로

same.push(100);
console.log(original);   // [ 1, 2, 3, 100 ]  ← same을 바꾸면 original도 바뀜!
```

`const same = original`은 **사물함 줄을 복사하지 않습니다.** 같은 줄에 이름표만 하나 더 붙입니다. 그래서 `same`으로 바꾸면 `original`도 바뀝니다. 진짜 복사본이 필요하면 `[...original]`을 씁니다. MDN: "You can use spread syntax to make a shallow copy of an array." 이 차이는 [[React]]에서 아주 중요해집니다 ([[JavaScript Core Syntax and Modern ES6+ Fundamentals]] 4.2절).

### 8.3 함수에 펼쳐서 넘기기

```js
console.log(Math.max(...[3, 9, 2]));   // 9  (Math.max(3, 9, 2)와 같음)
```

입문서는 같은 원리로 `addTwoNumbers(...arr)`처럼 배열을 함수 인수로 펼쳐 넘기는 예를 보여 줍니다 (p.151).

> [!note] 매개변수 자리의 `...`는 반대로 "모으기"
> 함수를 만들 때 매개변수 앞에 `...`를 쓰면, 남는 인수를 **배열로 모아** 받습니다. 이것을 **나머지 매개변수**(rest parameter)라고 합니다 (입문서 p.152).
> ```js
> function sumAll(...numbers) {
>   let total = 0;
>   for (const n of numbers) total += n;
>   return total;
> }
> console.log(sumAll(1, 2));         // 3
> console.log(sumAll(1, 2, 3, 4));   // 10
> ```

## 9. 맛보기: 배열 안의 배열

배열 안에 배열을 넣을 수도 있습니다. 극장 좌석처럼 **줄과 칸**이 있는 자료를 나타냅니다 (입문서 p.84–85).

```js
const seats = [
  ["A1", "A2"],
  ["B1", "B2"],
];
console.log(seats[1][0]);   // B1  (1번 줄의 0번 칸)
```

---

## 10. 정리

| 낱말 | 뜻 |
|---|---|
| 배열 | 값 여러 개를 순서대로 담는 사물함 줄. `[ ]` |
| 인덱스 | 칸 번호. **0부터** 시작 |
| `length` | 칸 개수. 마지막 칸 번호는 `length - 1` |
| `at(-1)` | 뒤에서 첫 번째 칸 |
| `push` / `pop` | 끝에 넣기 / 끝에서 빼기 |
| `unshift` / `shift` | 앞에 넣기 / 앞에서 빼기 |
| `includes` / `indexOf` / `find` | 있니? / 몇 번? / 조건에 맞는 첫 값은? |
| `for...of` | 값을 하나씩 꺼내는 반복 |
| `forEach` | 값마다 콜백 실행. 결과 없음, 중간에 못 멈춤 |
| `map` | 모든 값을 바꾼 새 배열 |
| `filter` | 조건에 맞는 값만 모은 새 배열 |
| `sort` | 원래 배열을 정렬. 숫자는 `(a, b) => a - b` 필요 |
| `...` (spread) | 배열을 칸칸이 펼치기. 복사·합치기에 사용 |

## 11. 자주 하는 실수

| 잘못 쓴 코드 | 결과 | 무엇이 문제인가 |
|---|---|---|
| `fruits[1]`로 첫 번째 값을 꺼내려 함 | 두 번째 값이 나옴 | 인덱스는 0부터입니다. 첫 번째는 `fruits[0]`. |
| `fruits[fruits.length]` | `undefined` | 마지막 칸은 `length - 1`입니다. 또는 `fruits.at(-1)`. |
| `for (let i = 0; i <= arr.length; i++)` | 마지막에 `undefined` 한 번 더 | `<=`가 아니라 `<`. |
| `fruits[-1]` | `undefined` | 대괄호는 음수를 뒤에서 세지 않습니다. `at(-1)`을 씁니다. |
| `[40, 1, 5, 200].sort()` | `[ 1, 200, 40, 5 ]` | 기본 정렬은 글자 순서입니다. `sort((a, b) => a - b)`. |
| `const copy = original;` 후 `copy`를 수정 | `original`도 바뀜 | 복사가 아니라 같은 배열을 가리킵니다. `[...original]`. |
| `const result = arr.forEach(...)` | `result`는 `undefined` | 새 배열이 필요하면 `map`이나 `filter`를 씁니다. |
| `arr.map(n => { n * 2 })` | `[ undefined, … ]` | 화살표 함수에 중괄호를 쓰면 `return`이 필요합니다 (레슨 07의 5.3절). |

## 12. 확인 퀴즈

**Q1.** 아래 코드의 출력은 무엇일까요?
```js
const colors = ["빨강", "주황", "노랑", "초록"];
console.log(colors.length);
console.log(colors[colors.length - 1]);
console.log(colors[1]);
```

> [!question]- 정답 보기
> `4`, `초록`, `주황`입니다. 인덱스 1은 **두 번째** 값입니다.

**Q2.** 아래 코드가 끝나면 `q`는 어떻게 될까요?
```js
const q = [3, 7, 2];
q.push(9);
q.shift();
```

> [!question]- 정답 보기
> `[ 7, 2, 9 ]`입니다. `push`로 끝에 9를 넣어 `[3, 7, 2, 9]`, `shift`로 앞의 3을 빼서 `[7, 2, 9]`.

**Q3.** `[2, 4, 6].map(n => n / 2)`의 결과는?

> [!question]- 정답 보기
> `[ 1, 2, 3 ]`입니다.

**Q4.** `[15, 22, 8, 30]`에서 10보다 큰 수가 **몇 개**인지 `filter`와 `length`로 구하세요.

> [!question]- 정답 보기
> ```js
> console.log([15, 22, 8, 30].filter(n => n > 10).length);   // 3
> ```

**Q5.** `[10, 1, 3].sort()`의 결과는 무엇이고, 왜 그럴까요?

> [!question]- 정답 보기
> `[ 1, 10, 3 ]`입니다. `sort()`는 기본적으로 숫자를 글자로 바꿔 사전 순서로 비교합니다. 글자 `"10"`은 `"1"`로 시작해서 `"3"`보다 앞에 옵니다. 크기 순서로 정렬하려면 `sort((a, b) => a - b)`.

**Q6.** 기온 배열 `[21, 25, 19, 30]`에서 가장 높은 기온을 `for...of`로 찾으세요. (`Math.max`를 쓰지 않고)

> [!question]- 예시 답안
> ```js
> const temps = [21, 25, 19, 30];
> let max = temps[0];
> for (const t of temps) {
>   if (t > max) {
>     max = t;
>   }
> }
> console.log(max);   // 30
> ```
> 처음 값을 "지금까지 가장 큰 값"으로 정해 두고, 더 큰 값을 만날 때마다 바꿉니다. `Math.max(...temps)`로도 구할 수 있습니다 (8.3절).

**Q7.** 아래 코드에서 `original`이 바뀌지 않게 하려면 어떻게 고쳐야 할까요?
```js
const original = [1, 2, 3];
const copy = original;
copy.push(4);
```

> [!question]- 정답 보기
> `const copy = [...original];`로 진짜 복사본을 만듭니다.

**Q8. (직접 해 보기)** 입문서 연습문제 3.1을 해 보세요 (p.78).
1. `"Milk"`, `"Bread"`, `"Apples"`가 든 장보기 배열을 만듭니다.
2. 길이를 출력합니다.
3. `"Bread"`를 `"Bananas"`로 바꿉니다.
4. 배열 전체를 출력합니다.

> [!question]- 예시 답안
> ```js
> const shoppingList = ["Milk", "Bread", "Apples"];
> console.log(shoppingList.length);   // 3
> shoppingList[1] = "Bananas";
> console.log(shoppingList);          // [ 'Milk', 'Bananas', 'Apples' ]
> ```

## 관점 비교 / 출처별 차이

| 항목 | 입문서 (2021) | 이 레슨 / MDN 기준 |
|---|---|---|
| 숫자 `sort()` (p.83) | "It sorts numbers from small to high"라고 하고, `[18, 72, 33, 56, 40]`이 크기 순서로 정렬되는 예를 보여 줌 | 기본 정렬은 **글자 순서**: "converting the elements into strings, then comparing their sequences of UTF-16 code unit values" (*Array.prototype.sort*). 입문서 예는 모두 두 자리 수라 우연히 크기 순서와 같음. `[40, 1, 5, 200].sort()`는 `[ 1, 200, 40, 5 ]` (Node.js v24.19.0) |
| 음수 인덱스에 대입 (p.76) | `cars[-1] = "Fiat"` 후 `cars[-1]`이 `Fiat`으로 나오는 것을 두고 "They suddenly exist"라고 설명 | 음수는 배열 칸이 아니라 배열 객체의 **별도 속성**이 됨: "Setting or accessing via non-integers will not set or retrieve an element from the array list itself" (*Array*). 실행해 보면 `length`는 그대로 2이고 `[ 'Toyota', 'Renault', '-1': 'Fiat' ]`로 출력됨 |
| 마지막 값 꺼내기 | `colors[colors.length - 1]` (p.77) | 같은 방법에 더해 `at(-1)`도 쓸 수 있음 (*Array.prototype.at*) |
