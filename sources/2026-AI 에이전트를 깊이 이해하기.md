# AI 에이전트를 깊이 이해하기: 설계 원리와 엔지니어링 실전

## 1. 핵심 테제 (Core Thesis)
**Bojie Li**는 현대 AI 에이전트를 **`현대 에이전트 = LLM(사고 엔진) + 컨텍스트(작업 정보 집합) + 도구(관측·행동 인터페이스)`** 라는 간명한 공식으로 정의하고, 모델 가중치 바깥에서 에이전트의 상한선과 신뢰성을 결정하는 시스템 공학을 **'하네스 엔지니어링(Harness Engineering)'** 과 **'루프 엔지니어링(Loop Engineering)'** 으로 체계화한다. 특히 단순 프롬프트 작성을 넘어 **KV Cache(Prompt Cache) 친화적인 컨텍스트 구조 설계**, **계층형 도구 발견과 [[Model Context Protocol (MCP)]]**, **코딩 에이전트의 메타 역량**, **통계적 에이전트 평가와 시뮬레이션**, 그리고 **사후 학습(Mid-training, SFT, 멀티턴 RL) 및 운영 궤적 기반의 지속적 진화 폐루프(Closed-loop Evolution)** 까지 에이전트 엔지니어링의 전 주기를 깊이 있게 다룬다.

## 2. 챕터별 핵심 요약 (Chapter-by-Chapter Summary)

- **Ch 1–2. 들어가며 & AI 에이전트 입문**:
  - **관측 공간(Observation Space)과 행동 공간(Action Space)**: 에이전트가 외부 세계를 인식하고 조작하는 인터페이스.
  - **하네스 엔지니어링(Harness Engineering)의 5요소**: 컨텍스트 엔지니어링, 메모리·지식 베이스, 도구 생태계, 상호작용 인터페이스, 오케스트레이션/가드레일.
  - **프롬프트 엔지니어링에서 루프 엔지니어링으로**: 단일 턴 호출이 아니라 다중 라운드 `ReAct(Reason + Act)` 루프 전체의 상태 전이와 오류 복구를 설계하는 패러다임 전환.
- **Ch 3. 컨텍스트 엔지니어링 (Context Engineering)**:
  - API 메시지(System, User, Assistant, Tool)가 Chat Template을 거쳐 모델 토큰으로 변환되는 과정.
  - **KV Cache 친화적인 컨텍스트 설계**: Transformer의 KV Cache(및 API의 Prompt Cache)는 **접두사(Prefix)가 1토큰이라도 바뀌면 이후 캐시가 전부 무효화**된다. 따라서 시스템 프롬프트·도구 정의·정적 문서는 앞쪽에 고정(Append-only)하고, 매 턴 변하는 상태 표시줄(Status Bar)이나 동적 정보는 컨텍스트 맨 끝에 배치해야 지연 시간과 비용을 최대 80–90% 절감할 수 있다.
  - **컨텍스트 압축(Context Compression)과 동적 스킬 로딩**: 긴 궤적에서 오래된 도구 출력을 요약/가지치기하고, 필요한 스킬(Skill) 문서를 온디맨드로 주입하는 전략 및 프롬프트 인젝션 방어.
- **Ch 4. 사용자 메모리와 지식 베이스**:
  - 사용자 메모리 시스템(단기·장기·선호도 메모리)과 평면 텍스트 청킹을 넘어선 구조화된 지식 그래프/하이브리드 RAG 파이프라인 구축.
- **Ch 5. 도구 (Tools)**:
  - 인식(Perception) 도구, 실행(Execution) 도구, 협업(Collaboration) 도구의 분류와 원자적·멱등적 도구 인터페이스 설계 원칙.
  - **도구 생태계와 대규모 도구 관리**: [[Model Context Protocol (MCP)]]와 스킬 허브, 그리고 도구가 수백 개로 늘어날 때 컨텍스트 오염을 막는 **계층형 구성 및 능동적 도구 검색(Active Tool Discovery)**.
- **Ch 6. 코딩 에이전트와 코드 생성**:
  - 코딩 에이전트(Claude Code, Cursor, Cline 등)의 내부 구조와, 왜 **'코드 생성·실행'이 모든 범용 에이전트(Manus, OpenClaw 등)의 핵심 메타 역량(Meta-capability)** 이 되는지 해부한다.
- **Ch 7. 상호작용: 관찰 공간과 행동 공간의 확장**:
  - 모달리티(텍스트, 음성, 비전 GUI Computer Use, 로봇 조작)와 타이밍(동기 요청-응답 vs 비동기 이벤트 기반 능동적 개입)의 2축 확장.
- **Ch 8. 에이전트 평가 (Agent Evaluation)**:
  - 에이전트 평가 지표 체계, 자동 평가 샌드박스, 통계적 유의성 검증, 에이전트 관측 가능성(Observability), 그리고 사후 학습의 다리가 되는 시뮬레이션 환경 구축.
- **Ch 9–10. 모델 사후 학습(Post-Training) & 에이전트의 지속적 진화**:
  - 사전 학습 -> Mid-training -> SFT(합성 궤적 데이터) -> 멀티턴 강화학습(RL, Rollout, 기여도 할당, 보상 설계, 증류)의 4단계 파이프라인(Ch 9).
  - 프로덕션 운영 궤적(Trajectory)과 Bad Case에서 학습 신호를 추출하여 에이전트가 매일 똑같은 실수를 반복하지 않도록 만드는 **지속적 진화 폐루프(Closed-loop Evolution)** 4대 기법(Ch 10).
- **Ch 11–12. 멀티 에이전트 협업 & 맺음말**:
  - 공유 컨텍스트 vs 비공유(격리) 컨텍스트 기반 멀티 에이전트 협업, 멀티 에이전트가 단일 에이전트보다 실제로 유리한 조건과 대표적 실패 모드, 모델과 에이전트 하네스의 공동 진화(Co-evolution).
