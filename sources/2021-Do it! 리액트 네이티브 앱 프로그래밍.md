## 핵심 요약 (Core Thesis)

856페이지에 걸쳐 **TypeScript + 함수형 컴포넌트 + React Hooks** 기반으로 [[React Native]] 앱 개발의 전 과정을 밑바닥부터 실습 위주로 파고드는 대작 입문·실전서다.

단순히 UI 사용법만 나열하지 않고, **Metro 번들러와 Gradle(Android) / CocoaPods(iOS) 네이티브 빌드 파이프라인의 실제 동작 원리(Ch 02)** 를 상세히 해부한다. 나아가 커스텀 훅(`useMemo`, `useCallback`, `useState`, `useEffect`, `useLayoutEffect`, `useRef`, `useImperativeHandle`), 고난도 애니메이션과 제스처(`Animated` + `PanResponder`를 이용한 드래그 앤 드롭 및 스와이프), [[React Navigation]] v5(Stack/Tab/Drawer), Redux 미들웨어(`redux-thunk`, `redux-logger`), 그리고 마지막 장에서 [[Expo]]와 Node.js/MongoDB/JWT 백엔드 인증 서버 및 카메라 앱까지 풀스택 모바일 개발을 완성한다.

## 챕터별 핵심 내용 요약

### 마당 1: 개발 환경과 리액트 네이티브 기초 (Ch 01 – Ch 03)
- **Ch 01. 리액트 네이티브 개발 환경 갖추기 (p.13–45)**
  - [[React Native]] CLI 프로젝트 생성(`npx react-native init --template react-native-template-typescript`)과 Windows/macOS별 Android Studio(JDK, SDK, AVD) 및 Xcode(CocoaPods, Watchman) 네이티브 툴체인 구축.
- **Ch 02. 리액트 네이티브 기본 다지기 (p.46–102)**
  - **프레임워크 작동 원리와 빌드 파이프라인 (p.47–59)**:
    - `npm start`: Metro 서버가 TypeScript/JSX 코드를 컴파일하여 ES5 JS 번들로 서빙.
    - `npm run android` (`./gradlew installDebug`, `build.gradle`) & `npm run ios` (`npx pod-install`, `Podfile`): `node_modules` 내 네이티브 모듈을 링크하고 네이티브 셸 앱을 에뮬레이터/시뮬레이터에 빌드·설치하는 내부 과정 ([[React Native Architecture (Bridge to New Architecture)]]).
  - 가상 DOM(Virtual DOM)과 물리 DOM, `React.createElement`와 JSX 구문, 코어 컴포넌트와 이벤트 속성(`onPress`, `onChangeText`).
- **Ch 03. 컴포넌트 스타일링 (p.103–193)**
  - `style` 속성과 `StyleSheet` API, `View` 컴포넌트와 CSS 박스 모델, 폰트/이미지/벡터 아이콘(`react-native-vector-icons`) 자원 활용 ([[Mobile Layout and Styling with Flexbox]]).
  - Flexbox 배치 속성(`flexDirection`, `justifyContent`, `alignItems`), `SafeAreaView`, `Dimensions`, `Platform` 및 재사용 가능한 커스텀 컴포넌트 설계.

### 마당 2: 함수 컴포넌트, 훅, 콘텍스트, 애니메이션 (Ch 04 – Ch 06)
- **Ch 04. 함수 컴포넌트와 리액트 훅 (p.194–301)**
  - 리액트 훅의 규칙과 메모이제이션(`useMemo`, `useCallback`), 상태 관리(`useState`), 생명주기/사이드 이펙트(`useEffect` vs 렌더링 직전 동기 실행되는 `useLayoutEffect`), 재사용 가능한 커스텀 훅(`useClock`, `useToggle`, `useAsync` 등) 작성법.
- **Ch 05. 콘텍스트와 ref 속성 (p.302–374)**
  - Context API(`createContext`, `useContext`)를 통한 다크모드(테마) 및 반응형 전역 상태 공유.
  - `useRef`와 `forwardRef`, `useImperativeHandle`을 통해 부모 컴포넌트가 자식 컴포넌트(예: `TextInput` 포커스 제어, `FlatList` 스크롤 제어)의 메서드를 명령형(Imperative)으로 호출하는 패턴.
- **Ch 06. 리액트 네이티브 애니메이션 (p.375–520)**
  - `Animated.Value`, `Animated.timing`/`spring`, `interpolate`를 활용한 페이드·이동·회전·스케일 변환 ([[React Native Gesture and Animation System]]).
  - 다중 애니메이션(`Animated.sequence`, `parallel`, `stagger`, `loop`) 조합.
  - **`PanResponder` API 심층 분석 (p.483–520)**: 멀티터치 제스처 수명주기(`onStartShouldSetPanResponder`, `onPanResponderGrant`, `onPanResponderMove`, `onPanResponderRelease`)와 `Animated.ValueXY`를 결합한 드래그 앤 드롭 및 좌우 스와이프 컴포넌트 직접 구현.

### 마당 3: 내비게이션, 리덕스, 엑스포 & 풀스택 실전 (Ch 07 – Ch 09)
- **Ch 07. 리액트 내비게이션 (p.521–627)**
  - [[React Navigation]] 패키지 아키텍처(`NavigationContainer`, `react-native-gesture-handler`, `react-native-screens`, `react-native-safe-area-context`).
  - Stack 내비게이션(화면 전환, 헤더 커스터마이징, 파라미터 전달), Bottom Tab 내비게이션, Drawer 내비게이션의 중첩 결합 구조.
- **Ch 08. 리덕스 이해하기 (p.628–724)**
  - 앱 수준 상태(App-level State) 관리를 위한 Redux 아키텍처(Action, Reducer, Store, `useSelector`, `useDispatch`) ([[Offline-First and Mobile State Management]]).
  - `combineReducers`를 통한 다중 리듀서 모듈화(로그인, 시계, 카운터, 멤버 관리) 및 Redux 미들웨어(`redux-logger`, `redux-thunk`)와 `AsyncStorage`를 결합한 비동기 영속 로그인 처리.
- **Ch 09. 엑스포 앱 이해하기 (p.725–846)**
  - **[[Expo]] 워크플로 비교 (p.726–750)**: Managed Workflow와 Bare Workflow 차이, `expo eject` 및 퍼블리싱.
  - **JWT 기반 인증 서버 & 카메라 앱 구축 (p.751–846)**: Node.js + Express + MongoDB + JWT 백엔드 서버를 직접 구축하고, 모바일 앱에서 회원가입/로그인 인증 및 카메라·갤러리 이미지 업로드(`FormData`)를 수행하는 풀스택 실습.
